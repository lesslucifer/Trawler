## [0.1.0] - 2026-11-06

The first public release.

### Added

- Capture HTTP and HTTPS from this machine, an iPhone or Android phone, the iOS Simulator and the Android emulator, set up from one screen.
- Filter the list with chips such as `status:4xx` or `-method:OPTIONS`.
- Read headers, timing and bodies, with viewers for JSON, XML, HTML, forms and more; open any value in its own window.
- Send a request again, edited, or write one from scratch.
- Export what you captured to HAR, and open a HAR file.
- Keep capturing with the window closed, from the menu-bar or tray icon.
- Update from inside the app. Every update is signed.
