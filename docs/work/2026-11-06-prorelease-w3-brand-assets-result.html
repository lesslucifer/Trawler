Deviations

The coloured tray ships one 32 px glyph, not the manifest's 16/20/24/32 and 22/24/32 sets: a Tauri tray takes one image and the OS scales it (32 → 16 is an exact halving). dmg-background.svg (1x) is not consumed; the @2x source draws the same art. No favicon PNG: both webviews show the SVG. The sources and MANIFEST.json are untouched.
