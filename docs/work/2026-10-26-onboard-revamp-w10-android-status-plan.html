E-ONBRVP.W10 — status: Android device

The Android device's certificate task blames only the refusal that could be its own test: the address step 4 offers. Android's own services never count. That refusal reopens the task after a proof, and the steps name the file and the menus a stock Android actually shows.

Requirement

The Android device's certificate task reads a refusal as its own only where the refusal is the address step 4 offers (example.com). Android's own services and apps that ignore a user certificate never turn it not working and never send anyone back to its steps. After a proof, the same address refusing reopens the task, so a removed certificate never reads done. Each step names the file the download leaves and a route to each menu that a stock Android has. A test holds each rule.

Part 2 — steps that cannot be done as written

As in W5–W8, each of these leaves a task waiting for a request that the step, as written, makes harder or impossible to produce.

#What goes wrong todayProposed fixRuling
C1 The file the steps name is not the file the download leaves. Both steps say trawler-ca.cer. Chrome on Android 15 saves trawler-ca.cer.crt, and the picker lists it as a CRT file (reproduced). The download step says what it downloads without a name it cannot promise: — it downloads Trawler's certificate. The install step picks the trawler-ca file it downloaded. The type that causes the rename is the core's (N3).
C2 The install path is not on stock Android, and differs by maker. Settings → Security → Encryption & credentials is Security & privacy → More security & privacy → Encryption & credentials on Android 15, and another path again on a Samsung. The Install anyway warning that comes before the picker is not mentioned (reproduced). Per Q3. A: Install it: in Settings, search CA certificate → CA certificate → Install anyway → the trawler-ca file it downloaded. The search reaches the installer whatever path a maker gives it.
C3 The proxy path is not on stock Android. Settings → Wi-Fi → the network → Proxy is Network & internet → Internet → ⚙ by the network → ✎ → Advanced options → Proxy on Android 12 and later (W8's C5). Settings' search finds no proxy (reproduced). The undo has the same path. Per Q3. A: the stock path, with a lead that says a maker's menus may differ: Settings → Network & internet → Internet → ⚙ by the network it is on → ✎ → Advanced options → Proxy → Manual. Undo: the same path, Proxy → None.
