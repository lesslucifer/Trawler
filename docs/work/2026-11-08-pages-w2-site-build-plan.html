E-PAGES.W2: cargo xtask site build and the checks that hold its output

The build W3's pages and W4's workflow run: a frame from site/, its markers filled from the files that own each fact, refused when any check is red.

v2 · 2026-11-08 (owner ruling: one same-origin script; Q13 flipped) · Trawler · T3 WU plan · E-PAGES.W2 · branch wu/pages/site-build off epic/pages · epic plan E-PAGES

Requirement

cargo xtask site build --release <json> --out <dir> copies the site/ frame into --out, fills its markers from README/PRIVACY (a subset markdown renderer that refuses unknown markdown), the release JSON (versioned releases/download/v<x>/… links for every Os::bundles kind, refusing a draft, a pre-release or a missing kind) and links.rs (guide and source URLs), copies the listed assets, allows exactly one same-origin script site.js held by a static scan, and owns the site base-URL constant https://lesslucifer.github.io/Trawler/; the same checks the tests run refuse the build before anything is written.

Flow

flowchart LR
  F["site/*.html · *.css (frame)"] --> FILL["fill markers"]
  R["README.md: h3 pitch · sub line · What you can do"] --> FILL
  P["PRIVACY.md: lead paragraph"] --> FILL
  J["release JSON (gh api …/releases/latest)"] --> FILL
  L["links.rs: SOURCE_CODE · USER_GUIDE"] --> FILL
  FILL --> MEM["files in memory + ASSETS"]
  MEM --> CHK{"checks"}
  CHK -- "red" --> X["refused, nothing written"]
  CHK -- "green" --> OUT["--out (must be empty or absent)"]

An unknown marker, or one left unclosed, refuses the build. Files that are not .html/.css are copied as bytes.

What the build refuses

InputRefused when
release JSONdraft or prerelease true, a tag without v or with a pre-release -n, an Os::bundles kind × arch with no asset, two assets for one id, an installer whose name lacks the version, no SHA256SUMS
versionsthe release is newer than the workspace version (package::version_of)
markdownanything outside the subset: raw HTML, ![, headings, tables, quotes, numbered or nested lists, single */_, \, ~, an unclosed `/**/link
--outexists and is not empty (a stale file would ship)

Checks over the built files (build and tests share them)

CheckRed when
linksa relative or {{path}}-rooted href/src/srcset/CSS url() does not resolve to an output file (or its #id); an absolute href is neither SOURCE_CODE[/…] nor BASE_URL…; a blob/main/<file>#anchor names a file or heading the tree lacks; the guide link is absent
no external requestthe CSP meta is missing, altered or doubled (exact: default-src 'none'; img-src 'self'; style-src 'self'; script-src 'self'; base-uri 'none'; form-action 'none'); an absolute src/srcset/url(); an absolute <link href> other than rel="canonical"; an address (//, http:, https:) outside an href or a content under BASE_URL; any // in a stylesheet; any @import, <iframe, <form, <object, <embed, <style, style=, meta refresh
script (owner ruling)a <script> that does not load site.js by src or has an inline body; an inline on*= handler; any other .js; site.js over 4096 bytes or naming fetch, XMLHttpRequest, WebSocket, sendBeacon, EventSource, import, eval, Function, cookie, localStorage, sessionStorage, indexedDB, serviceWorker, Worker, SharedWorker, WebTransport, RTCPeerConnection (whole words) or ://
deny-listpublic_text::denied_names finds a name in any built text file
downloadsthe set of releases/download/ links ≠ Os::bundles kinds × arch at v<version>, or one points at another tag
contrasta --text* token on a --bg* token below 4.5:1 in the light :root or the prefers-color-scheme: dark :root (dark inherits what it does not override); a non-hex value for either
