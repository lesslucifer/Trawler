Requirement

.github/workflows/ci.yml has three jobs, on macos-latest, ubuntu-22.04 and windows-latest. Each installs the UI's packages from the lockfile, then runs cargo clippy --workspace --all-targets --all-features -- -D warnings and cargo test -p trawler -p trawler-ui, with the same triggers, read-only permissions and timeout as today. The Ubuntu job installs the Tauri build libraries before any cargo step and runs the tests under xvfb-run. No step can fail without turning its job red. The tree is clippy-clean under both Rust 1.97 and 1.99.
