What this epic learned about itself

PatternWhere it showed up
Measure before you fix, and let the measurement say no. W3's benchmark refused two of three planned changes. E-REDESIGN was right to defer these to a WU with a benchmark first, and the deferral's value is precisely the two fixes that did not land.
Facts folded into one value produce a fix per round, forever. W6 took six rounds because three facts — did the core answer, what did it say, did this flow's fetch produce anything — were encoded in two values. Rounds 2, 3 and 4 each found the defect inside the previous round's fix. Round 4 stopped patching and split the model.
A document lies about its own counts more readily than about the code. Of W9's fifteen verified findings, not one was in the code — every one was a false sentence in the WU's own report or notes. The habit that closed it: state no total a table already carries, and grep every carrier for a retired claim, git notes included.
A comment asserting an invariant the code does not enforce is a question. W6's folded boolean sat under a comment that was true of the case the design walked through and quietly assumed of every other. Three of ten round-1 candidates were that assumption being wrong in three ways.
