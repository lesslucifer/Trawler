Requirement

The iPhone's certificate task reads a refusal as its own only where the refusal is the address step 4 offers (example.com). Apple's own services and apps that pin never turn it not working and never send anyone back to its steps. That refusal names the trust switch first and the profile second, because nothing the screen reads tells them apart. After a proof, the same address refusing reopens the task, so a removed profile or a trust switch turned off never reads done. A test holds each rule.
