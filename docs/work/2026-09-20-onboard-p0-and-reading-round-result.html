The review's own F11 row had offered both homes (src/reach.rs or the shell for interface names); the shell is the one the project's record allows. The temporary/stable IPv6 flag is the host's to print, so it goes with the shell-out that read it — and the core now says in its own words why it ranks IPv6 no finer
