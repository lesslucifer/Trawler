E-GATEBM.W2 — walk-error waiver valve (R5)

A recorded, per-seam escape hatch on the epic tip's cr/v2 note that suppresses a single walk seam failure — a surgical override that isn't the blanket --no-verify.

v1 · 2026-07-07 · Trawler · T3 WU plan · epic plan · solution discussion

Requirement

The epic-gate walk must let a single seam failure be suppressed by a walk_waivers: [{seam, why}] entry on the epic tip's cr/v2 note: when a failed seam's sha matches an entry with a non-empty why, the walk records waived: <why> for that seam instead of failing — every other seam and every non-walk check still runs — and the un-waived seam failure's fix line names the exact waiver command and warns against --no-verify.

Mapping

E-GATEBM · R5 (surgical, recorded, reviewable walk-error suppression that isn't --no-verify), R4 (the cr/v2-carrier rationale — a waiver is a review judgment and cr is diff-bound — recorded in the workflow-gates DEC at epic close).

Expected result

  • CrNote (notes.rs) gains an optional walk_waivers list of {seam, why}.
  • The walk loads the epic tip's cr note once and, for each seam failure, matches the seam sha against the waivers; a match with non-empty why turns the failure into a recorded waived line (visible in output) rather than a red failure.
  • A missing entry, or one with a blank why, does not waive — the seam stays red, and its fix line instructs the exact git notes --ref=cr waiver edit and explicitly warns off --no-verify.
  • The waiver keys on the whole seam sha (per-check granularity deferred); it applies only to walk failures, never to the tip's own non-walk checks.

Test plan

  • Unit (notes.rs #[cfg(test)]): CrNote parses a walk_waivers list and tolerates its absence; a helper resolving "is seam S waived?" returns true only for a matching sha with a non-empty why, false for a blank why or a non-match. Covers the code this commit adds.
  • Integration (xtask/tests/dod_gate.rs): on a real temp repo with a genuinely red walk seam — (a) adding a matching walk_waivers entry to the epic tip's cr note makes the epic gate green while the seam is reported waived; (b) a blank why leaves it red with the instructing fix message; (c) a non-walk check on the tip is unaffected by the waiver. No waivers intended at the test level.
