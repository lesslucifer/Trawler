Requirement

On the iPhone or iPad, each state of the setup screen leads with the one thing to do next. Because nothing on this machine can act on a phone, that thing is the scannable code of the next task, and it is the one framed control. A code is offered only once scanning it can work. Every Settings step is path parts in iOS 26's own words, starting from the screen iOS itself puts first. Every task has its way back. What explains shows only on request (W13's R1). A test holds each rule.
