Requirement

On Another Ubuntu machine, on every host, each state of the setup screen leads with the one thing to do next. Every word names one thing one way, never a desktop or API name, and is true on the host it is shown on. Each by-hand step on that machine offers a route without a terminal or sudo where one exists, with verified media, and keeps its command as the other way. Every way back undoes every way in. What explains shows only on request (W13's R1). A test holds each rule.
