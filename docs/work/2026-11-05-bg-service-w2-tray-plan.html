E-BGSVC.W2 — the menu-bar icon

A tray icon present whenever the app runs: it shows the capture service's state, reaches the window, restarts a stopped core, and is what lets W1's windowless mode exist at all.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · WU plan · branch wu/bg-service/tray off epic/bg-service · epic plan: E-BGSVC · builds on W1

Requirement

Every launch builds a menu-bar icon before the launch window is decided. Its glyph and first menu line follow the core's state through the supervisor's observer (Capturing · Capture service starting · Capture service stopped · Attached to <api>). Its menu offers Open Trawler, Settings…, Restart capture service (enabled only while an owned core is stopped, through the supervisor's own restart) and Quit Trawler. Whether the icon could be built is recorded as the host's tray availability, which W1's decisions read.

From this WU the tray is real, so stays_windowless turns true wherever keep-capturing.json says on. No UI writes that before W6. Quit from the tray (as ⌘Q) still closes the main window, which hides instead of quitting in that state; W3 splits quit from close. Restart is greyed out rather than removed while running: the menu keeps its shape and the item's place.
