Deviations

The plan's authors/homepage on trawler and trawler-ui extends to all four workspace crates: one rule over every member is smaller than a per-crate list. The plan's licenseFile is dropped: the packaging test showed tauri-bundler embeds it as the .dmg's licence agreement, so hdiutil attach stopped at an agree prompt (and every user would click through one). The check now refuses a licenseFile (DEC-87 rule 1).
