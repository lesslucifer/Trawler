E-INSPWIN.W10 — decode skips a JSON escape

In a JSON document, the value decode finds never begins on the letter of an escape, so replace with decoded keeps the document valid.

v1 · 2026-11-05 · Trawler · T3 WU plan · E-INSPWIN.W10 · branch wu/inspect-window/json-escape-decode · from the epic review's FAIL on e31e8d4b · epic plan (archived)

Requirement

In the data window's JSON surface, decode (right-click or ⌘⇧D) finds a value that starts after any escape sequence before it — \n, \b, \uXXXX and the rest — never on the escape's letter, so replace with decoded leaves valid JSON holding the escape and the decoded text.

Mapping

E-INSPWIN · UC-9 decoder rows · epic expected row 8 (replace works) · DEC-75 rule 11 (decode reads a value one way) · the epic review's verified important: {"a":"\bGVsbG8="} replaced into {"a":"\lello"}, which no longer parses.
