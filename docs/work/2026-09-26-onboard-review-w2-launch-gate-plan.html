E-ONBREV.W2 — the launch gate

The app shows setup only once it knows capture is unproven: never while the launch read is in flight, never for a core that did not answer, and never because of a row Trawler imported or sent itself.

v1 · 2026-09-26 · Trawler · T3 WU plan · E-ONBREV.W2 · branch wu/onboard-review/launch-gate · epic plan · findings R1–R3 · depends on E-ONBREV.W1 (merged, the before is recorded)

Requirement

Only a row with source: "captured" and an https:// URI proves setup or feeds the setup screen's traffic reading. While the launch read is in flight the window shows the shell and the checking dot and no instruction. A launch read that fails keeps the app checking under the "not answering" statement and reads again when the core answers, instead of opening setup. The setup screen carries the same statement while the core is silent. The "You're set up" banner appears only for a captured row that started after setup opened.
