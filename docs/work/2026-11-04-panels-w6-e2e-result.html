Deviations

WhatWhy
a drag is dispatched as pointer events on the separator, not as WebDriver pointer actionsthe embedded WebDriver (tauri-plugin-wdio-webdriver 1.2) turns every pointer action into a synthetic mouse event at the point, so React's pointer handlers never see a WebDriver drag; the spec dispatches at the same layer the driver does
splitter keys are dispatched as keydown on the focused separator, one per callthe same driver's key table has no Home or End (they arrive as raw code points); one key per call so each step reads the value the last one rendered
the quit clears the session id on the runner's own browser instancethe runner skips its session delete only without an id, and the global browser is a get-only proxy
