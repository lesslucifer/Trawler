E-BGSVC.W1 — the app outlives its main window

The shell half of windowless capture: a keep-capturing preference, an exit decision that reads it, a main window that can be rebuilt, and a launch that can skip it.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · WU plan · branch wu/bg-service/outlive-window off epic/bg-service · epic plan: E-BGSVC

Requirement

With the shell preference keep_capturing on and a menu-bar icon available, destroying the main window leaves the app and its core running with no window (Dock icon hidden on macOS), and a second launch or a Dock click rebuilds the main window through the same builder launch uses; in every other state, destroying the main window quits exactly as today, and --background skips the launch window only when the app may be windowless.
