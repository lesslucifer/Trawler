Freshness-gate spec (for the later build WU)

flowchart LR
  SRC["ui/src/components/*.tsx
TSDoc = truth"] --> GEN["gen-index
(deterministic)"]
  GEN --> IDX["index (committed,
generated file)"]
  IDX --> GATE{"gate: re-run gen-index,
git diff vs committed?"}
  GATE -->|"differs"| RED["❌ stale — run gen-index"]
  GATE -->|"identical"| GREEN["✅ fresh"]
Store nothing forgeable. The gate regenerates the index from the real .tsx and git diffs against the committed copy — the committer never supplies the comparison value, so a hand-edited index or a pasted hash can't pass. Same pattern as Cargo.lock freshness / verify-doc. W2 specifies this; a later WU / W7 builds it.
