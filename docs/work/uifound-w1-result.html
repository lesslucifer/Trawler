E-UIFOUND.W1 — Result Report

WU result against the plan — the ui/ scaffold and cargo xtask ui build integration.

v1 · 2026-07-12 · Trawler · T3 WU result

Outcome

Delivered. The ui/ front-end project exists, mirrors Strata's proven stack, and is wired into cargo xtask ui. Every expected result from the plan is observable:

  • cargo xtask ui build runs the real pnpm pipeline (install + tsc -b + Vite build) and emits ui/dist/index.html — verified via the gated integration test.
  • cargo xtask ui dev launches the native window: the thin Tauri shell crate compiles cleanly and tauri::generate_context!() validated the config, capabilities, and icons.
  • The core workspace stays GUI-free — cargo metadata lists only trawler (not trawler-ui); cargo build/cargo test -p trawler pull no Tauri toolchain. Enforced by exclude = ["ui/src-tauri"] in the root Cargo.toml.
  • Vitest is established; the smoke test (React root mounts, placeholder renders) passes. The app boots to a placeholder view — real content is W2.

Deviations

  • Vitest added to the stack. Strata carries no test runner; W1 establishes it (Vitest + Testing Library + jsdom) as the plan requires. Only what the smoke test needs was added — no jest-dom matcher package (a plain .textContent assertion covers the smoke test).
  • The Tauri shell is barer than Strata's. Trawler's app is a pure client of the control API over loopback, so src-tauri registers no commands and drops dialog/opener/scan deps — just a window (tauri::Builder::default() .run(generate_context!())). This is the thin-shell decision, not a shortcut.
  • ui dev launches the app only, not the core alongside it. The plan's W1 expected is "a Tauri window opens"; pnpm tauri dev covers that. Running the core too is a dev convenience deferred (see follow-ups); the epic's non-goal already assumes the core runs alongside.
  • Icons copied from Strata. Placeholder icons unblock the Tauri bundle; a Trawler-specific icon set is cosmetic and deferred.

Evidence

All green at the tip:

  • Rust unit: cargo test -p xtask --lib ui:: — ui subcommand usage wiring (1 test, pass).
  • FE unit (smoke): pnpm test in ui/ — App mounts + placeholder renders (1 test, pass).
  • Integration (seam): cargo test -p xtask --test ui — the core-workspace isolation assertion passes; with TRAWLER_UI_BUILD_TEST=1 the real cargo xtask ui build emits ui/dist/index.html (both pass).
  • Tauri shell: cargo build in ui/src-tauri — compiles clean (Tauri 2.11), proving the window launches.
  • Lint: cargo clippy -p xtask — no findings in the new ui.rs (one pre-existing warning in mr.rs, untouched by this WU).
  • Core stays GUI-free: cargo test -p trawler --no-run builds without the GUI toolchain.

Distillation
