Deviations

Plan D2 changed in review round 2: the shape comes from the label when one names a form, and only a form the user picks is read from its bytes, because a label-blind read turned real URL-encoded bodies carrying a raw " or a leading / into not a form or a URL. D8 widened: the pane uses readForm for every shape. One addition to the plan: row decode now finds a token inside a value. Without it, open all's JWT journey (E-INSPWIN2 expected #4, a right-click on Bearer <jwt>) would have regressed once headers read as a table. No new kind, no new decode affordance. No path-segment rows: the path row wraps whole. e2e not run (see Evidence).
