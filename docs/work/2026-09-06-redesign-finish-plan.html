Intent

E-REDESIGN put all five shipped screens through the design flow and proved the design → build citation path for the first time. It closed delivered — and with ten open follow-ups, because the epic gate is the wrong moment to change unmeasured performance, to widen a pane the shell design owns, or to fix a docstring that has no cr/v3 note to live on. Those items were not oversights; each was deferred with a named home, and this epic is that home. It carries two kinds of work. Debt — four registry docstrings that cite code E-REDESIGN deleted, three measured-nowhere performance costs the rebuild introduced, and a flow list that cannot say the API is unreachable because useFlows catches and discards every fetch failure. Design questions — the detail pane is 380px and that width is half the header-wrap cost DEC-32 exists to bound; the status filter is a free-text u16 when the useful query is a class; and the payload cell is waiting on its second truncation sighting to earn a registry entry. What it no longer carries is a re-design. W10's own result shipped the setup screen and quit dialog "gated, not endorsed as final", and this epic opened that re-design as W7 and W8 — until W7's run came back and the owner ruled the rebuild its own epic (see the scope change above). Why now, for what remains: every one of these items is addressed, in writing, to "whichever epic next opens this file", and the debt rows name files the shell/list track opens anyway. Paying them here is what keeps the review cost paid once instead of three times.

Use-case requirements

Two native contracts are touched, and neither is narrowed. The third — UC-ONBOARD — left with the re-design at v2 and is listed below only so its absence is deliberate rather than silent.

  • UC-4 Watch live traffic in the native app. Two contract-level gains: the list states when the API is unreachable instead of showing a stale list indistinguishable from a quiet proxy (W6), and the status filter accepts a class — 4xx — end to end (W5 + W6). The detail pane's width becomes a designed value rather than a token nobody chose (W4 + W6).
  • UC-5 Inspect a captured flow. No capability moves. The body view switch is re-labelled to the terms its contract actually settles on — raw | pretty — closing the one-term-per-concept violation E-DFLOW.W6 recorded (W9). The wider pane changes how much of a long header value is readable without expanding it, which is the observable half of DEC-32.

No E-RFINISH WU opens Onboarding.tsx, ProxyCloseDialog.tsx or setup.ts, so the contract stands exactly as shipped for the whole of this epic — including DEC-13's inherited assertion that stop routing appears only after the proxy was set. E-ONBOARD is where the promise-by-promise audit is answered.
