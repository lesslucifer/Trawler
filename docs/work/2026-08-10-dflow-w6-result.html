E-DFLOW.W6 result — Revise the rulebook and close the vocabulary

The result report this WU tip attests. The rulebook stopped describing a vocabulary and started pointing at one that cannot be disobeyed. Every scale in ui/tailwind.config.js now replaces Tailwind's rather than extending it, so an off-list value emits no CSS; a local ESLint rule is the alarm that silence needs; and all thirteen hard rules carry a Tier-1 predicate, so the gap line finally reads 13/13 machine-checked (design). Nine live defects were found along the way — every one by executing against the real artifact, none by the type-checker and none by the test suite.
