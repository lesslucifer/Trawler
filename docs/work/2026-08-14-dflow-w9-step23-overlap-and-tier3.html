③ Tier-3 — red before green

The plan's precondition: a doctored copy of the closed design, carrying one dishonestly paraphrased @avoid, must return FAIL before the real design may be judged. Both submissions used the same finder against the same rulebook pin (b769f7e), taken from cargo xtask design-scope origin/epic/design-flow HEAD. The doctored copy lived only in scratch: never in the tree, never in design-scope's output, never in a note.

The paraphrase that was falsified. In the Notice catalog row, the cited @avoid clause was replaced with one the TSDoc does not contain:

  • it caught the planted defect first, and rated it a blocker — the acceptance test the plan demanded, passed;
