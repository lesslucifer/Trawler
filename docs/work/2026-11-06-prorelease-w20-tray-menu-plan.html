E-PRORELEASE.W20: the tray menu's commands

Round 1, audit and proposal: what the menu-bar / tray icon offers today on each OS, what a debugging proxy's user expects from it, and the owner questions that decide round 2's build.

v1 · 2026-11-06 · Trawler · T3 WU plan (round 1: the build waits on the owner's answers) · E-PRORELEASE.W20 · branch wu/prorelease/tray-menu off epic/prorelease · epic plan E-PRORELEASE · amends DEC-77 rule 8 · UC-BG · DEC-64

Requirement

The menu-bar / tray icon offers, on every OS and with no window open, each command a user needs to reach Trawler, see whether it captures and whether this machine routes through it, check for updates and quit; every label names what its item does in the lexicon's words, and no item shows an address.
