E-PRORELEASE.W22: an unavailable open-at-login is a state, with the way by hand

0.1.0-6 shows a Mac's unavailable login item as a refused save ("couldn't save — unavailable — macos …"); rc7 wrote the by-hand steps into GUIDE.md's Open at login section, and the app does not point at them.

v1 · 2026-11-07 · Trawler · T3 WU plan · E-PRORELEASE.W22 · branch wu/prorelease/login-message off epic/prorelease · epic plan E-PRORELEASE

Requirement

On a Mac whose build cannot register a login item (an ad-hoc-signed build; DEC-77 v6 rule 9), Settings → General shows 'open Trawler at login' as unavailable with the shell's reason verbatim (no 'couldn't save' prefix, 'macOS' capitalised), and a 'how to do it by hand' button that opens the user guide's open-at-login section (copy-address fallback when the browser will not open).
