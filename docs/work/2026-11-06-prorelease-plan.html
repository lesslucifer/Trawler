Logo — three directions (owner picks, Q3)

The UI is warm-dark with zero chromatic accent (DEC-19): canvas #2b2622, ink #f7f5f0, ink-strong #dad2c1, mute #aea69c; the wordmark is Instrument Serif italic. Each direction keeps that palette; only C spends one semantic colour.

A · The net

A trawl net drawn as 4–5 converging hairlines closing into a knot, ink on a canvas squircle. Says "captures what passes through". Tray glyph = the same cone, solid. Scales well to 16px as a triangle-ish silhouette.

B · The serif T

Instrument Serif italic "T" in ink on canvas, one thin horizontal line crossing the stem (the wire). Matches the existing wordmark exactly; most restrained. Weak at 16px unless the stem is thickened for the small sizes.

C · Hook and packet

A hook catching a pair of braces { }, ink on canvas, with one ok-green #4cc38a dot as the "capturing" light; tray running = dot shown, stopped = dot hollow. Most literal; the only one that spends colour.
