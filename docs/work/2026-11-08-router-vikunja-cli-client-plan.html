E-VIKUNJA.W2 plan: the cargo xtask vikunja client

One command per step of the router's Vikunja protocol, so no router turn hand-writes a REST call.

v1 · 2026-11-08 · Trawler · T3 WU plan · E-VIKUNJA.W2 · wu/router-vikunja/cli-client → epic/router-vikunja

Requirement

With only the router token at ~/.config/trawler/vikunja.key, cargo xtask vikunja init|show|read|put|create verifies the token, lists open tasks (and the owner's needs-owner queue), reads one task with its comments and relations, applies any mix of comment / assignee / label / relation / done changes to a task in one invocation in the protocol's order, and creates an epic or WU task with its parent and blocking relations — every task-field write being a read-modify-write of the whole task.

Mapping

E-VIKUNJA, summary block W2 "xtask vikunja CLI client"; the interface vikunja-protocol.md names for its raw-REST section. Process epic, no UC.
