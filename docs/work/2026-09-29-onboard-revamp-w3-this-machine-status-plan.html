Requirement

Each of This machine's steps shows the state something on this machine verified: the exact certificate Trawler uses, and the proxy the system uses now. Each step is read again whenever its answer can change, within seconds. A test holds each detector and each trigger.

Mapping

E-ONBRVP · epic W3 block · UC-ONBOARD: This machine's status rows · the owner's "proof expires" rule, decided for This machine · DEC-62 (new, amends DEC-33) · the Simulator shares step 2's detector, so it gets D3, D5 and U1–U4 too.
