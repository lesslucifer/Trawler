The measurement, and the plan row it broke

D6·A said: "the trigger cannot fire on landed history — no schema discriminator, no cutoff, no walk waiver." Measured with design-scope over every first-parent seam: it fires on W5's seam (f2a2b7c, wu/design-flow/revise-registry), which added 25 surfaces — twenty-odd registry components and the Gallery screen — and the epic walk re-verifies that seam at WU level. The plan's "0 of 11" was measured over the epic→main merges on main, which this epic's walk never re-verifies. It measured the wrong seams.

What grandfathers it is the discriminator that already exists. Every seam in this epic carries a cr/v2 note, and a cr/v2 note cannot be given a citation after the fact without claiming a reading nobody did — the identical argument DEC-24 makes for the design section. So the handoff's silence is reported as 9·design-schema on a v2 note and 9·design on a v3 one, and the walk drops the former at seams exactly as it already does. No new discriminator, no cutoff, no walk waiver — D6·A's conclusion holds even though its premise did not.

The second thing the code said

A design section with nothing judged was being asked for a verdict and a rulebook pin. check_design validated verdict and the pin whenever the section existed — harmless while the only reason to write one was a judgment. A build's note now carries the section for its citation, and an epic's for its drop record: demanding a PASS over an empty artifact list would have made both notes claim a review nobody ran.

So check_design now returns as soon as the diff carries no design artifact, and verdict is optional in the schema. Nothing judged, nothing claimed — and the design-bearing path is untouched, which the existing tests and the flow e2e still assert.
