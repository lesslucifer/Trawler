E-ONBREV.W3 — re-entry is a new setup session

Opening setup starts a fresh reading. Traffic from before it, the list's filter and the device already proven no longer decide what the screen opens, shows or says.

v1 · 2026-09-27 · Trawler · T3 WU plan · E-ONBREV.W3 · branch wu/onboard-review/reentry-session · epic plan · findings R4–R7 · depends on E-ONBREV.W2 (merged: since is recorded, and proof reads captured rows only)

Requirement

A setup session starts at the since its opening records. Every reading the setup screen takes from traffic reads only captured rows and tunnels that started at or after since: the try task, each task read from traffic, the one-open-guide rule and the success line. Those rows are listed unfiltered, whatever filter the list holds. The header dot reads connected once capture has been proven. "Set up another device" never opens on This machine. It opens on the last platform chosen in this app session when that was another one. Otherwise the question stays unanswered, and no task shows until one is chosen.
