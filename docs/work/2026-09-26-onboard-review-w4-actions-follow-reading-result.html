Follow-ups

  • W6: UC-ONBOARD's one-act row says the two single commands "survive as the manual route beneath it". They are now each task's own route, under the one act in task 1. Its reversal row says "the certificate's removal is in the steps below". It is now step 1's to remove it later, and the line says so only where the certificate reads trusted.
  • W5: this machine's proxy task never reads done from traffic, because the try-it command names the proxy itself. Where W5 makes the Linux probe answer unknown, that task's promise to "confirm this on this machine's first request" is one no request can keep. W5 words that reading.

  • W1's harness: one launch flaked in one of the four runs that finished. macos-this/sent-only painted neither the setup screen nor the list within 30 s, then passed twice alone in under a second each. The launch seeds a sent request before the app starts; the flake is on that path, not on the onboarding screen.
