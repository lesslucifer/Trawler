E-ONEAPP.W1 — the repo is one workspace, and cargo run is the app

The app crate joins the core's workspace and embeds the front-end bundle. The core's entry gains the flags and the ready line that W2's supervisor will drive.

v1 · 2026-11-03 · Trawler · T3 WU plan · E-ONEAPP.W1 · branch wu/one-app/one-workspace · epic plan · depends on none

Requirement

A bare cargo run at the repo root builds the front-end bundle when it is stale and opens the Trawler window from the embedded bundle. cargo run -p trawler is the headless core, which still links no GUI crate. Both the core binary and the app's --core mode accept --ca-dir, --proxy-port, --api-port and --lifeline, print one JSON ready line with the bound addresses on stdout, and with --lifeline exit cleanly when stdin closes.
