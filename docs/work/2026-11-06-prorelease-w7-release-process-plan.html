A written release process, notes that say what changed and how to verify the download, a SHA256SUMS asset, and one hand-check matrix.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W7 · branch wu/prorelease/release-process off epic/prorelease · epic plan E-PRORELEASE

Requirement

Every release's notes open with "What's new" taken from the version's CHANGELOG.md section and end with how to check the download against SHA256SUMS; release-manifest refuses a version with no section and writes SHA256SUMS for every installer, which release.yml re-checks and attaches; a T1 release doc states the version policy, publish rules, rollback and the final's cut; a T2 hand-check matrix lists each OS × step.
