The oracle is not wired into verify-doc

Nothing runs the ui suite automatically — not gate0, not pre-commit, not pre-push, and there is no CI in the repo; verify-dod reads the test/v2 note rather than re-running anything. So this check is enforced the way all 768 other ui tests are: an agent runs pnpm test and attests it. That is no weaker than the rest of the front end, and it is not an automatic backstop — a later WU that reintroduces a stale citation and skips the suite would not be stopped by any gate. verify-doc already shells out to node for the vocabulary and registry oracles, so wiring this one in is small and would give it a real gate. Recorded in DEC-35.
