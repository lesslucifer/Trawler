Requirement

readKind(bytes, label?) returns one of nine kinds (json · form · xml · html · javascript · css · text · hex · image) with what decided it — the label or the bytes, and the label as served — by the table below, and DEC-77, DEC-78 and DEC-79 are in docs/decisions/ with wrap-not-truncate naming DEC-77 as its second escape.
