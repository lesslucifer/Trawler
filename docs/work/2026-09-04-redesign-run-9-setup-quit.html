        └────────────────────────────────────┘   bordered remedy

scroll / overflow: the dialog is capped at dialog-max (384px) wide; E and H are
fixed height, F wraps, G is the only unbounded zone (step count and command
length vary by target) — it wraps rather than truncates and the dialog body
scrolls at the viewport, not G itself. The scrim never scrolls.

zone H is the dialog's only action row, in every mode and every state: the exit
on the left as a bare Button, the remedy on the right as a bordered one. Frame,
not colour, ranks them — Button has no primary variant. Zone G holds one
left-aligned control, the manual fallback, so no two controls ever stack at the
same weight. Where no remedy exists (remote), H holds the exit alone; where the
remedy failed, the same slot relabels to "try again" rather than emptying.

Both surfaces cap at dialog-max — the same 384px measure. That is deliberate: setup and the dialog are the same voice at two moments, and a shared measure is what makes the second feel like the first.

The dialog's three modes

Today's code collapses foreign and none into one info-only notice. That is wrong on the domain: unset_proxy turns off whatever proxy this host has — unset_proxy_commands sets the OS proxy state to off, it never checks whose address is in the box. So a foreign proxy is as unsettable as ours, and the split that matters is is there a proxy on this host, not is it ours.

proxy_statusmodeWhat the user is offeredOpt-out?
ours ours zone H: quit (bare) and turn it off (elevated, bordered) · zone G: the collapsed manual command as the fallback no — there is a real remedy
foreign foreign the same H row and the same G fallback, differently worded: the proxy is not ours, so the stake sentence says what will break rather than implying Trawler set it no — there is a real remedy
none remote no remedy exists, so G renders the per-target steps inline for a phone or emulator fixed by hand, and H holds quit alone — the same button in the same corner yes — the only mode that can ask forever

What this changes from the run's first pass: foreign moves from read-only instructions to a real action, the opt-out narrows from two modes to one, and zone G gains the same collapsed target-picker + command the setup screen already has — so the manual route survives a refused or failed elevation in every mode where an action exists.
