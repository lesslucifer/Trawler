E-QUERY.W1 — lists, negation and is in the core

The listing, export and clear take every filter key repeated, a not_ form of each, and is. The host filter stops dropping the port.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-QUERY.W1 · branch wu/query-bar/filter-lists · epic plan · base c30852c5 · rules from DEC-71

Requirement

GET /flows, GET /flows/export and DELETE /flows select one set for one query string: a repeated q matches all of its values, any other repeated key any of its values, not_<key> excludes what <key> would select, is takes pending or https, the host filter matches host or host:port, a single parameter behaves as before, and an unreadable value is a 400 naming the parameter as sent.

Mapping

E-QUERY · the W1 summary block in the epic plan · UC-3·UC-4 listing contract, UC-6 export, UC-7 clear · the host port bug found in the epic's research · DEC-71 rules 1–7.
