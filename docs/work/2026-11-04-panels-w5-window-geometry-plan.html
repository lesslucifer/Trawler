E-PANELS.W5 — window geometry

Each window reopens at the size, place and maximized state it was left in, moved onto a monitor that still exists.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-PANELS.W5 · branch wu/panels/window-geometry · epic plan · base 8196a699

Requirement

The shell records each window's size, position and maximized state by window label as the user moves and resizes it, saves the records to windows.json in its config directory when a window closes and when the app exits, and at launch puts a window with a record back at it — placed inside the work area of the monitor it overlaps most, or centred on the primary monitor when none is left, never below the window's minimum size — while a missing or unreadable file leaves every window at its configured default.

Mapping

E-PANELS · UC-4 (window row) · the epic's expected results 4 (the window survives a relaunch) and 5 (a broken save gives the default; a window saved on a gone monitor opens on a visible one) · rulings Q1 (keyed by window label, for E-INSPWIN), Q2 (shell-side file in the app config dir), Q3 (one record per window label), Q4 (no version field) · DEC-67's read-whole-or-not-at-all rule.
