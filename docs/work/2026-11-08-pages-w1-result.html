Deviations

Two calls the brief left to W1, both stated in the design: the hero gets a line under the buttons in a detected state (the picked file name, Other systems, Other downloads, and a copy of that card's first-open line). That is where the ruling's “sets the first-open line” lands. And the privacy sentence names GitHub as the host that sees each visit, so “no tracking” cannot be read as “nobody sees the request”. The plan's “No OS detection” line (Design) and its non-goal line are superseded by the D2 ruling; the plan itself is not edited here. The design-review skill's scope is unchanged from round 1: cargo xtask design-scope finds no design artifact in the range, so no design/v1 note is owed. Docs-only WU: the test layers are waived, and W2 and W3 carry the tests this design specifies.
