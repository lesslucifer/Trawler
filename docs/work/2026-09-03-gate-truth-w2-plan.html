E-GATETRUTH.W2 — implement the citation predicate

The gate encodes DEC-28: a citation the tip does not ship resolves at the path's last state reachable from the tip. Green on the history every build WU now produces, red on a path nobody shipped and on a blob the path never carried — each refusal naming the half that failed.

Requirement

The fixtures that would have caught P1 exist at all three test levels.

Non-goals

  • No new note field. design.retired was rejected in DEC-28; the shape stays path · blob · built.
  • No content check. The gate asks whether the design existed and which bytes were read, never whether the build honoured them.
  • No change to when retirement happens. components·unretired and 6·retirement-order are untouched; the WU changes what the gate accepts, not when the file must go.
  • No doc rule text. W1 landed the T1 and T2 truth; this WU's distillation is the result doc plus the epic plan's W2 row. DEC-28's "W2 owes" bullet is settled by the code, and the result doc says so.
