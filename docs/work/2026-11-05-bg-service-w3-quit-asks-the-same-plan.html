E-BGSVC.W3 — every quit Trawler can hold asks the same

The close request and the quit request come apart: ✕ may keep capturing, ⌘Q and the menu-bar's Quit always run DEC-64's check, and the first ✕ that would quit asks once.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · WU plan · branch wu/bg-service/quit-asks-the-same off epic/bg-service · epic plan: E-BGSVC.W3 · design: W5's run (blob 38a949ad)

Requirement

A quit request (⌘Q, the menu-bar's Quit Trawler) always brings the main window up and runs DEC-64's check there, then exits — never merely hides the window, never exits unchecked. A close request (✕) closes at once and reads no proxy when keep capturing is on and a menu-bar icon exists; asks the once-question first when the switch is unanswered and a menu-bar icon exists; and otherwise runs DEC-64's check before it quits. The once-question stores its answer as the switch; ✕ or Esc on it cancels and stores nothing.
