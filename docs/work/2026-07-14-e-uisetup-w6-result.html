PainFix, as built
P1 Verify dead-end The Verify step renders a concrete prove-it: "open any website, or run the command below" plus a copyable curl -x http://<addr> https://example.com carrying the real proxy address (proveItSnippet). Green still flips only from a real decrypted flow.

P3 Buried happy path On macOS/Windows the one-click action is primary; the per-OS manual steps collapse behind a "Set it up manually" disclosure that force-opens on an auto-setup failure. Non-auto OSes stay inline.
Enabling signal FlowEvent::ConnectionSeen + a store counter + GET /stats + connection SSE. A CONNECT whose handshake fails (untrusted CA) now leaves a trace, so the proxy step goes green on any traffic, decrypt or not.

Two truths, wired

  • Local probe (~90%). ca_trusted (new, CN match) + W5's existing proxy_status (host:port classify). Run on entering onboarding and re-run after an action; failures fall back to unknown, never a false "not set up".
  • Observed traffic. App threads { decrypted, trafficSeen } into Onboarding — decrypted = an https:// flow (W4), trafficSeen = any flow OR connections > 0 (seeded from /stats, bumped on the connection event via useFlows).
  • Reveal stays capture-only. A probe-green or a bare connection never reveals the list — only a decrypted flow does (unchanged from W4).

Deviations from plan

CA probe matches on Common Name, not SHA-256 fingerprint (owner-approved). Avoids a crypto dep in the thin Tauri shell. Ceiling: a stale cert reusing the CN "Trawler Proxy CA" would read as trusted; the upgrade path (hash the live /ca.crt DER, match the store's fingerprint line) is a ponytail: note in setup.rs.

No new proxy probe. The plan's "proxy → us?" probe is W5's shipped proxy_status verbatim — "ours" ⇒ the step is green. Reuse, not a new command.

e2e: W4 spine only. The connection-goes-green-before-decrypt path is proven hermetically at integration (untrusted_https_records_a_connection_not_a_flow); the WebDriver harness only drives a trusted proxied request, so the untrusted case isn't re-asserted there. The 4-spec journey stays green.
