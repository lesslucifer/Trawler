One ⋮ trigger, three worded acts, two asks and a marked row. The three doors the API has had since W2 reach a person, and two things the design could not change itself — the window's minimum width and the CORS grant hiding the export's filename — are paid here.

ModalShell moves to a module of its own rather than being exported from the screen it lived in The run's warrant for keeping it local was "a general Dialog drawn from the app's only dialog would generalise from a sample of one" — a statement about the collection, not about the file. Importing it out of a sibling screen is the shape the collection exists to prevent; a module is neither that nor a registry entry, and the promotion stays the proposal it was.

The ✕ gained a caller-supplied name, defaulting to its old one E's escape is a button named cancel, and the frame's ✕ was also named cancel — two controls under one name doing the same thing. The default keeps ProxyCloseDialog unchanged (its own escape is quit, so it never collided).
import is disabled while the textarea is empty, rather than refusing with a sentence The refusal wordings on this surface are all the server's. Inventing a client-side one for "you have typed nothing" would put a sentence on the screen that no contract owns; the file picker is the other way in and is never disabled.
The in-flight line appears in both A′ and F during an import The run's TonedText row lists all three slot states and its Interaction row puts a mute Notice in the dialog. Both, because a modal covers the header: neither zone is inferable from the other.

Deviations

FromWhat changed, and why
the epic plan's useConfirm for the clear confirmation Carried, as both design runs required. useConfirm is a ~2 s after-the-fact flash that reports rather than asks, and an irreversible act needs a question. The ask is a modal on ModalShell. The plan's claim stays wrong on the record; this is the deviation it predicted.
the WU plan's observable 11 — "the shipped and e2e Tauri configs both declare minWidth ≥ 850" The e2e config is an overlay that declares no window block at all, so it inherits the minimum rather than declaring one. The guard asserts the shipped value and asserts that the overlay still declares no windows — which is the condition under which the inheritance holds, and the thing that would silently break it.
the run's focus-returns-to-origin reading of M Honoured, but by a mechanism worth naming: DOM focus never leaves the trigger while M is open — movement is virtual, exactly as Select already works. So "focus returns to the trigger on every exit" is true by construction rather than by restoration, and the tested distinction between Esc and Tab is which one consumes the key.

One thing the build found

A request-only flow cannot be exported, and that is HAR, not a defect. Writing the integration test caught it: har_entry requires a response, so a pasted curl command — and any flow still in flight — is skipped by GET /flows/export while appearing in GET /flows. That is W2's deliberate contract (a HAR entry without a response is not a HAR entry), and it means the epic's round-trip guarantee never covered the curl door's output. Recorded rather than silently worked around; the export/import parity claim is about captured exchanges, which is what DEC-35 already scopes it to.

correctness openFile and its browser fallback shipped untested — every test that "chooses a file" mocks openFile itself, so neither branch ever ran. Against "no change lands without its test", with no waiver. Confirmed and covered: the Tauri branch (a dismissed dialog answering null with no read attempted, a picked path returning name and bytes, single-file not directory) and the browser fallback (the cancel listener that is the whole reason a dismissal settles, a chosen file, a change event carrying none, and a read that fails). The verifier had established this was an omission and not a harness limit — jsdom dispatches the events — which is what made it actionable.
correctness The export and import share one transfer slot, and the import act is never disabled during an export — so opening the import ask mid-export and merely dismissing it cleared the export's "exporting…" line while its request was still in flight. The clear is now scoped to its own transfer: the import path takes down the line only when the line is the import's. The finder's larger claims — a second concurrent export, and the two flows overwriting each other's failure — were refuted: the ask is a true modal whose backdrop sits above the menu's layer and whose trap excludes it, so the trigger is unreachable while it is open, and the two failures are separate local state.

And one the review did not ask for, found while writing its test. Covering openFile exposed that a failed read never settled its promise — and that choose() ran as void choose(), so a rejection from the Tauri picker was swallowed whole. Either one leaves the ask sitting there having done nothing and said nothing, with its controls disabled for a wait that never ends. The fallback now rejects rather than hanging, and choose catches, so a picker that fails lands in the same warn Notice every other failure on this surface does — which is what the run's any of the three fails outright row asks for. Both paths are tested.

The eight refuted are worth one line, because two of them are the design working as intended: CaptureMenu duplicating Select's popup shell and its panel classes is the duplication run 11 foresaw verbatim and reserved for the collection's owner, and the lint rule validates each design-allow pragma independently. The rest: a one-line error-unwrap idiom shared with Onboarding under different contracts; setState after unmount, which React 18 makes a documented no-op and which is the pre-existing ProxyCloseDialog pattern this diff extracted; ImportDialog's local busy flag, whose proposed removal cannot work because onBusy is the parent's only channel; an unread ChosenFile.name, the documented mirror of a saveBody return callers already discard; the computed CAPTURE_COPY key, which tsc proves typo-proof; and a Blob copy in a branch the shipped Tauri app never takes, bounded by the ring's cap, in code this diff does not touch.

  • Run 11's second blocked-on is carried, not closed. A cross-year timestamp still overruns cell 1 by 7.2px, and DEC-34's escape is still unavailable because the detail pane shows no timestamp. The two exits are unchanged — a wider cell 1 paid out of PATH, or a full timestamp in the detail pane — and both are whole-grid calls this WU has no design for. Owner stays the flow-detail run.
  • Three proposals remain unpaid, all with named owners: Dialog (promote ModalShell, now a module and one import away from the collection), Menu (mint, or extract the popup shell Select already owns and have both consume it), and the more glyph entry. Each is now built and proven in one call site, which is a better starting point for its owner than a description was.
  • A request-only flow is invisible to the export — see above. Worth stating in DEC-35 if a reader ever asks why a pasted command does not come back out; not amended here because the record already scopes the guarantee to captured exchanges.

No debt discovered beyond those. No test layer skipped beyond the recorded e2e waiver.
