E-GATEBM — epic result

The DoD gate's seam walk now recognises back-merges of landed history and carries a recorded, per-seam waiver valve — so a walk misfire never again forces a blanket --no-verify.

v1 · 2026-07-07 · Trawler · T3 epic result · epic plan

Outcome

Delivered against the epic intent and all three expected results. (1) A stale epic that back-merged an advanced main now walks clean — the spurious 7·walk·1·notes line on the integration seam is gone. (2) A genuinely ungated forward WU seam still turns the walk red — the R2 guardrail holds, by construction (a forward seam is never an ancestor of the target). (3) A walk seam failure is suppressed by a walk_waivers entry on the tip's cr/v2 note; without a non-empty why it stays red, and the red output names the exact waiver command and warns off --no-verify. No product use-case (no UC-*) touched — process/tooling epic on the workflow gate.

Per-WU rollup

  • E-GATEBM.W1 — target-reachability discriminator: delivered. is_landed_history skips a seam whose merged-in parent is an ancestor of the epic mainline or the gate target; target threaded into walk(). Merged --no-ff with green DoD-W (test/cr/doc + receipt).
  • E-GATEBM.W2 — walk-error waiver valve (R5): delivered. CrNote.walk_waivers + walk_waiver_for; record_seam routes every seam failure through the waiver check and surfaces a visible WAIVE line; manual review stays unwaivable. Merged --no-ff with green DoD-W.
  • Standalone (epic-level): the epic e2e test commit, carrying its own test/v2 · level: commit note; the DEC-8 distillation commit and this result — docs, each with a Reviewed-By trailer.

Deviations

No scope deviations from the plan. Two in-spirit refinements, both recorded in the WU results: the waiver valve was wired for every walk seam class (not only three-parent WU seams) since R5 insures against any future unclassifiable topology; seam matching is sha-prefix-tolerant so the abbreviated sha the walk prints can be pasted straight into the waiver. One out-of-scope discovery in W1: the full test suite was momentarily red on entry from a stale CARGO_MANIFEST_DIR baked into a cached test binary from a deleted sibling worktree — a build-cache artifact cleared by recompile, not a code defect.
