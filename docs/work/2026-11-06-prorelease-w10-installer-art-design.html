Layout grammar shared by all four

RuleWhy
Only the signed palette, plus three art-only tokens: paper #f4f1ea, deep amber #a8741a, label chip #7a756famber #e0a43a is 2.0:1 on paper, so arrows on light use deep amber (3.6:1). After sign-off, add the tokens to the DEC-89 palette
No live text: the wordmark and the tagline are the outlined paths from social-preview.svgDEC-89 rule 2; rsvg-convert output does not depend on the fonts installed on the build machine
Plain fills: no gradients, filters, masks or var(); canvases opaqueBMP is 24-bit with no alpha; rsvg-convert renders what the doc shows
Windows text areas stay white: NSIS header and WiX banner art sits outside the title area; the WiX dialog art stays in the left 164 pxWindows draws the page text in black over these bitmaps
DMG labels sit on a mid-grey chip (240–262 pt, 120 wide, under each icon)Finder draws icon names black in light mode and white in dark mode; only a mid tone passes 4.5:1 for both

Technical constraints per consumer (verified)

Versions: Cargo.lock pins tauri 2.12.5 and tauri-utils 2.10.2 (the config schema). The bundles are built by @tauri-apps/cli 2.12.4 (ui/package.json ^2.12.4), whose native binary embeds tauri-bundler 2.10.4.
