The check — what makes a citation resolve

A docstring is prose, so the oracle must separate a citation from an English word. Two token shapes are citations and nothing else is: a path (x.tsx, optionally :N) and a two-hump name ([A-Z][a-z0-9]+([A-Z][a-z0-9]+)+). The second shape is what makes this tractable — it admits HeaderTable, DotStatus, StepStatusView and ReactNode while excluding every prose capital in the corpus: Inter, Pass, Enter, Space, Blob, Date, Warp, JSON, WCAG, ASCII and the shouted STANDING/UNLESS/NEVER.

Resolution is derived from the tree, never transcribed — the same discipline design-vocabulary.mjs states for its own mapping. A name resolves if it is any one of:

SourceDerived fromWhat it admits
exported identifierexport function|const|type|interface|class|enum X and export { … } across ui/src/**StatusTone, DotStatus, StepStatusView, StepTone, every component
module namethe basename of every non-test .ts/.tsx under ui/src/**BodyViewer, FlowDetail, FlowList
imported bindingevery name any ui/src file importsReactNode — cited by StepList, owned by React
dependencyui/package.json, scope and segments folded to lowercase alphanumericsCodeMirror → @codemirror/*, cited by four renderers

A path resolves against git ls-files — “the tree it ships with” is exactly what is tracked, and no deny-list of build outputs can drift out of date — and a bare basename resolves as readily as a full path. That last point was forced by the tree: JsonRenderer and XmlRenderer both cite decode.rs, which is real, at src/api/decode.rs. Prose names a module the way a reader says it aloud, and legislating full paths in TSDoc would be a design rule this WU is not entitled to make — so the check asks whether the repo holds the file, not how the docstring spells it.

The oracle does not verify that a :N pin still points at the right line — it cannot know what the line should say, and a check that only counts lines would pass a rotted pin. That residual is stated here rather than half-solved; the one pin in the corpus is being deleted, not re-aimed.
