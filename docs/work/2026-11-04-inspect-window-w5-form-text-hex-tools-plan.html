E-INSPWIN.W5 — form, text, XML and hex tools

The data window's toolsets for every kind but JSON: find in the form table and the hex dump through W4's bar, sort by key, show encoded and copy as JSON on a form, wrap long lines, and XML re-indent as a working-copy step.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-INSPWIN.W5 · branch wu/inspect-window/form-text-hex-tools · epic plan · builds the design run

Requirement

The data window finds (a count, N of M, stepping by key) over a form's keys and values and over a hex dump's bytes — a query of hex pairs read as bytes, anything else as text, saying which, matches crossing row boundaries; a form sorts by key as an undoable step, shows itself encoded as editable text, and copies its pairs as JSON with repeated keys and empty values kept; the text kinds wrap long lines or not; and XML re-indents as an undoable step that keeps every text and attribute as written, or says where it is not well-formed.

Mapping

E-INSPWIN · UC-9 form, text, XML and hex rows · epic expected rows 6 (form) and 7 (text, XML, hex with find) · builds the run's FindBar on hex (as bytes · as text), the ⋯ form section (show encoded, sort by key, copy as JSON), wrap long lines ⌥Z and XML re-indent ⌥⇧F. W3 already built the form's edit, add, remove and copy the value.
