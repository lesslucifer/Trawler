Requirement

Each of Another Mac's steps reads only evidence that could have come from that Mac: traffic since its address was allowed, and never traffic this Mac sends. Each proof carries its time. Step ① says when the address that Mac uses is no longer this Mac's, within seconds. A test holds each rule.
