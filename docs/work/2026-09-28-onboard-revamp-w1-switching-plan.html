E-ONBRVP.W1 — moving between the list and setup

What the app shows, keeps and checks again each time you move between the flow list and the setup screen.

v4 · 2026-09-28 · Trawler · T3 WU plan · E-ONBRVP.W1 · branch wu/onboard-revamp/switching · epic plan · depends on none
Every point is ruled ("the plan is ok, now let's build W1", 2026-09-28): S5 taken, Q5 and Q6 as proposed. Built; the design round (round 10 of the setup screen's design run) waits for your review.

Requirement

The dot switches between the list and setup at any time, and shows whether Trawler captured anything in the last 3 minutes. A core that does not answer is stated on both screens, with a retry, and blocks setup. Every move between the two screens keeps, checks again or starts fresh exactly what UC-ONBOARD's table says, and a test holds each row.

Mapping

E-ONBRVP · the epic plan's W1 block · UC-ONBOARD: a new "moving between the list and setup" section · F23 (the dot reads the traffic), moved here from W2 · a new DEC-61, because two E-ONBREV rules change (see your proposals).

A click always switches screens: from the list it opens setup, and from setup it opens the list. The quiet state's look is chosen in the design round. The palette has only green, red and grey, so a hollow green ring is one option. An http request turns the dot green, but it never turns setup's certificate step green.
