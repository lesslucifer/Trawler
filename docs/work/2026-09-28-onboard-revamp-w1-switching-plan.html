E-ONBRVP.W1 — moving between the list and setup

What the app shows, keeps and checks again each time you move between the flow list and the setup screen.

v2 · 2026-09-28 · Trawler · T3 WU plan · E-ONBRVP.W1 · branch wu/onboard-revamp/switching · epic plan · depends on none
What I need from you: a yes or no on the four questions at the end, and a ruling on each problem in the problems table. I build once those are answered.

Requirement

The dot switches between the list and setup at any time. It shows whether Trawler captured something recently, not just once. Every move between the two screens keeps, checks again or starts fresh exactly what UC-ONBOARD's table says, and a test holds each row.

Mapping

E-ONBRVP · the epic plan's W1 block · UC-ONBOARD: a new "moving between the list and setup" section · F23 (the dot reads the traffic), moved here from W2 because the dot is being redesigned here · a new DEC-61, because two E-ONBREV rules change (see your proposals).

The dot, after this WU

DotWhenExample
grey · checkingthe app has just started and is asking the core what it has capturedthe first second after launch
red · not set upno https request has been captured since the app starteda fresh install, or a Mac whose certificate is not trusted yet
new · quiethttps was captured earlier, but nothing in the last 5 minutesyou set up this morning, then turned the proxy off
green · capturingan https request was captured in the last 5 minutesyou are browsing through Trawler right now

Clicking the dot always switches screens: from the list it opens setup, and from setup it opens the list. The quiet state's look is chosen in the design step. The palette has only green, red and grey, so it could be a hollow green ring, for example. The 5 minutes is question Q1.

Questions for you

#QuestionMy proposal
Q1How long without a capture before the dot turns quiet?5 minutes. Setup's own "nothing arriving right now" uses 30 seconds, but on the list a dot that changes every half minute would flicker whenever you pause
Q2"At any time": does that include the first check at launch?No. The first check lasts 5 seconds at most, and until it answers the app does not know which screen is right (S1). After that, the dot always switches
Q3Should "back to flows" also show before anything is captured, to match the dot?Yes. Two controls that go to the same place should follow the same rule
Q4What makes the dot green: only a decrypted https request, or plain http too?https only. Plain http proves the proxy works but not the certificate, and that is today's rule for "set up"
