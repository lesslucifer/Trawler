E-RFINISH.W1 — the design specs prescribe the shape the gate enforces

Two T1 specs still tell an author to load the pre-bundle trio. DEC-26 replaced it with one classic tag, and the checks moved with it — so a design file built to component-design.html's skeleton today is refused by the render gate, and a run built to design-flow.html's mockup template is refused by assets·specimen for a path that is one directory level short.

WU plan · 2026-09-06 · Trawler · T3 (docs/work/) · wu/redesign-finish/design-file-skeleton → epic/redesign-finish · DEC-26

Requirement

Both T1 design specs prescribe exactly the asset shape their gate enforces — component-design.html's file skeleton loads the CDN, specimens.bundle.js at the depth a file under docs/work/components/ reaches it, and Babel, and shows the text/babel mount from window.Trawler into spec-* hosts that check-render.mjs requires; and design-flow.html's mockup template names the bundle at the exact src string xtask/src/doc.rs matches on — so that an agent who follows either spec to the letter produces an artifact that passes, and a future divergence between a spec's prescribed path and the gate's constant fails a test instead of a design run.
