E-ONEAPP.W4 — a quit says what it now does

The app now owns its core, so quitting stops the capture service. The quit dialog says so, and an integration test proves the terminate path does it.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-ONEAPP.W4 · branch wu/one-app/quit-truth · epic plan · depends on W2

Requirement

When the app owns its core, the quit dialog says that quitting stops Trawler's capture service, in place of "once … stops", in the ours, unread, devices and emulator cases. When the core is attached, or its state has not been read, the dialog keeps today's sentences. The stale sentence ("isn't answering") is the same in both. Every exit the shell sees (RunEvent::Exit: ✕, ⌘Q, the Dock's Quit, a logout) stops an owned core and leaves an attached one running.
