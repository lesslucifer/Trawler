Membership is @tier — the waiver, and the loud failure

The plan asks for two failure modes that are easy to confuse and must not be: a component deliberately outside the vocabulary, and a component whose block is broken. A short roster emitted quietly is the defect the oracle exists to prevent, so the two get opposite treatments.

The blockOutcomeWhy that way
no TSDoc block, or one with no @tier absent the waiver, stated in the file it waives. useConfirm.ts is a hook and index.ts is the barrel; neither declares a tier, so neither is in the vocabulary and no list anywhere had to say so
@tier present, another of the five missing or empty throws declared is not the same as stated. The message names the file, the tag, and the five a registry entry declares
@tier that names no tier throws quotes what it read back — the shape W6's round 9 established, a red that does not guess at a cause it cannot know
two @tier blocks in one file throws ambiguous, and first-wins would silently pick one. W6 ⑥ closed the same class of ambiguity rather than guessing at it

Gate: deleting @states from Notice.tsx fails the collection suite at load with Notice: @states is missing — a registry entry declares @tier @use @avoid @states @madeof. Deleting CutMarker from the barrel reds the equality assertion. Both verified by mutation, then reverted.

Why a redirect is a whole name

A citation is a roster name matched at word boundaries in the @avoid text. The alternative — any capitalised word — was measured first and rejected: over the real corpus it also returns Enter, Inter, CodeMirror, BodyViewer, HeaderTable, Field and StatusDot.

RejectedBecause
every capitalised word is a citation a keyboard key, a typeface and a library are not components, and no rule tells them apart from StatusDot — a component that really is missing. Keeping the noise means a hand-typed allow-list, which is the transcription this step deletes
substring matching Notice's @avoid names CopyButton and never Button; a substring rule invents the second pair. Pinned by its own test

StatusDot and Field are cited by an @avoid and have no component — both are named out of scope by this WU's plan, and the emitted registry does not pretend to judge them. What the derivation does still catch is the gap W5 found: the roster comes from the folder's TSDoc and the barrel is authored separately, so a cited component that exists but is unexported still reds.

What stays hand-written in collection.test.tsx is the one thing no TSDoc can carry: the props each component needs to mount. ROSTER is renamed SPECIMENS to say so, and its keys are now asserted against the vocabulary rather than standing in for it.

One thing that cost time

new URL(x, import.meta.url) is a vite build pattern, not a path expression. Vite rewrites that exact form into an asset reference, so the collection path resolved to http://localhost:3000/src/components.tsx under vitest while import.meta.url itself was the correct file:// URL — the misleading part. dirname(fileURLToPath(import.meta.url)) + resolve is not affected, and is what scripts/build-specimens.mjs already does. Two config workarounds were tried and reverted before the reading was correct; the fix was to use the pattern the repo already had.
