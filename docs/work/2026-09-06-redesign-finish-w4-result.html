Three things the run found that the plan did not predict

Finding · escalated

The shell has no valid arrangement at its own minimum window

path = window − pane − 612. With the pane open, the row's fixed tracks overflow below a window of 992px at the shipped width — and tauri.conf.json declares a minimum of 800. Below the threshold the row region scrolls horizontally while the column-label row above it does not, so the labels and the cells they name come apart.

Widening the pane raises the threshold to 1132. The run refused both ways of making that disappear on paper — raising the minimum window narrows a capability the list alone uses today, and paying for the pane out of the host column decides the row grammar the epic's non-goals reserve — and escalated it with the numbers instead.

Finding · designed

Q2 and Q3 were one design

The same swallowed failure hides both. Type a letter in the status box today and the API returns 400, useFlows discards it, and the list silently freezes — the one state on this screen where the user's own keystroke causes an unexplained stall. It is a separate cause from an unreachable core (the API answered; it said no), so it gets its own sentence rather than sharing one.

Finding · fixed and recorded

The mockup rendered nothing, and every gate said green

Babel transforms type="text/babel" on DOMContentLoaded, and the htmldoc skeleton's bootstrap is a type="module" tag — which defers that event until its own fetch settles. With the doc server answering in ~6 s, six empty mounts and no console error, while verify-doc reported 13/13 hard rules and assets·specimen green, because neither check opens the page.

Established by A/B: bootstrap removed → 7 of 7 mounts; bootstrap intact with async → 7 of 7. The run carries async. The shape is everyone's — every design run in the repo renders a blank mockup whenever the doc server is slow — so it is on the run's blocked-on list with the general fix named. A first diagnosis (a raw <body> in a prose <pre>) was wrong; the tag is escaped anyway, and the run records the wrong turn rather than only the answer.
