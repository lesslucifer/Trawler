Design run — the replay composer

A developer takes a flow, changes one thing, sends it, and reads what came back, or writes a request from nothing. The composer takes the detail pane, and the result lands in the list beside it as a new flow.

Draft mockup

Every composed element is mounted from the collection, window.Trawler. Screen-owned: the zoning, the header rows, the row notes, the list rows, the capture menu drawing, and Field's multi-line form, which is a proposal and is drawn in Field's own box. The draft is live: type in any field and the marks follow. The buttons under the mockup set a state. Each one is meant to be read alone.

overflow: list is the flow list's own scroller, unchanged, and a sent row lands at its bottom in wire order. identity is pinned and bounded: one control row and one provenance line. request is the one unbounded zone: n header rows and a body. It scrolls as a whole. The body's multi-line field takes a caller-set height (body-max, 256 px) and scrolls its own text, and a body over TEXT_MAX (128 KiB) or not UTF-8 never enters it. send is pinned to the bottom of the pane, one line; a ⚠ sentence wraps there and is never cut. entry is the inspector's header and flow line, bounded.

Run #7's four Tune calls, applied. Send precedes its verdict. The per-row mark is the only edited signal, and no zone carries a modified badge. The result has no border, because the pill's tone is the channel. The send zone is pinned at the bottom, so the scan runs identity → edit → fire.

A draft shows what will be sent. Content-Length and the connection headers are rewritten by the core whatever the draft says, so they are not editable rows. A box whose edits are ignored would show a value that is not sent. One line under the headers names each and why. The Host row stays, shows the URL's host while nobody has typed in it, and is sent as typed once someone has.

A sent answer has no ✓. The exchange happened, and what it said is the pill's to tone. A ✓ beside a 500 would contradict it. Only a send that got no reply gets a verdict line, ⚠ with the core's own words.

One draft, and the door that made it reopens it (epic decision 8). replay on the flow a kept draft came from reopens that draft with its edits. replay on any other flow, or new request, starts a new one and replaces it. new request reopens a kept draft from scratch the same way. start over in the composer returns to the seed.
