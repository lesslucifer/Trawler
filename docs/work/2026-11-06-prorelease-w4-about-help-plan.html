E-PRORELEASE.W4: About, Help and the version on every OS

Built from the signed W13 design run (D1–D9): Trawler's own About window with three pages, a Help menu per OS, the version, check now and the auto-check switch in Settings → General.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W4 · branch wu/prorelease/about-help off epic/prorelease · epic plan E-PRORELEASE · design run W13 (closed)

Requirement

On macOS, Windows and Linux the user opens one About window (version, licence, copyright, logo, user guide, report an issue, source code) with Third-party licences and Privacy pages; the Help menu opens the guide, a prefilled issue (version, OS and its version, CPU, install kind; nothing about traffic or the machine), the licences and the privacy page; Settings → General shows the version, check now and check for updates automatically (default on, stored, honoured by the launch check).

Shape

flowchart LR
  M["menu.rs · Help per OS · About item"] --> A["about.rs · window 'about' · page"]
  M --> L["links.rs · guide · issue · source → opener"]
  A --> P["About.tsx · About · Licences · Privacy"]
  P --> L
  S["General.tsx · Updates block"] --> U["update.rs · auto switch · check(ByUser)"]
  U --> LA["check_at_launch honours the switch"]

The webview never hands the shell a URL: it names a link (guide · issue · source) and the shell builds the address.
