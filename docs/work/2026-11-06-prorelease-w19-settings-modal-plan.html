E-PRORELEASE.W19: Settings is a dialog of the main window

Owner request: Settings is no longer a detached window; it is a dialog on top of the main window and blocks it, from every place that opens it, the menu-bar / tray icon included.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W19 · branch wu/prorelease/settings-modal off epic/prorelease · epic plan E-PRORELEASE · design W19 design (ruled)

Requirement

Every way of opening Settings (app menu ⌘, / Ctrl+,, the capture controls' Settings, the menu-bar / tray icon's Settings…) and About (app menu About, Help → About Trawler, Third-Party Licences, Privacy, a link the browser would not open) shows it as a modal dialog inside the main window, which takes no input until it closes; with no main window (windowless, DEC-77) the main window is rebuilt first; Esc, the dialog's ✕ and ⌘W / Ctrl+W (Trawler's own Close Window: topmost dialog first, else the window) end it; a request while another dialog is up waits; a quit request (DEC-64) is never blocked by it.

Status

Ready (round 2). Owner rulings 2026-11-06 in the design doc: shape A (in-window ModalShell), tray rebuilds main first, About is the same kind of dialog, ⌘W closes the topmost dialog, a request waits behind another dialog, data windows stay free.
