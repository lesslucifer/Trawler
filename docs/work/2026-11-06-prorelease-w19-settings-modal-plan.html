E-PRORELEASE.W19: Settings is a dialog of the main window

Owner request: Settings is no longer a detached window; it is a dialog on top of the main window and blocks it, from every place that opens it, the menu-bar / tray icon included.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W19 · branch wu/prorelease/settings-modal off epic/prorelease · epic plan E-PRORELEASE · design W19 design (round 1, open questions)

Requirement

Every way of opening Settings (app menu ⌘, / Ctrl+,, the capture controls' Settings, the menu-bar / tray icon's Settings…) shows it as a modal dialog over the main window, which takes no input until Settings closes; with no main window (windowless, DEC-77) the main window is brought up first; Esc and the dialog's close end it; a quit request (DEC-64) is never blocked by it.

Status

Round 1 is investigation only. The shape (in-window dialog vs native modal window) and the About rule are owner questions in the design doc; this plan is revised to ready with the ruled shape before any code.
