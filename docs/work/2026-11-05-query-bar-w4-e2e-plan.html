E-QUERY.W4 — the query bar end to end

A WebDriver spec walks the chip flows in the real window against a real core, the specs that typed into the retired controls move to chips, and the T2 docs state the grammar and the reversal.

v1 · 2026-11-05 · Trawler · T3 WU plan · E-QUERY.W4 · branch wu/query-bar/query-bar-e2e · epic plan · base 2913e91d · rules from DEC-71

Requirement

In the real window over a real core, the query bar builds chips from suggestions alone, the list holds still while a draft is typed and moves at each chip, a misspelt key stays a draft that says why, Backspace removes the last chip, the window's query selects exactly what export and clear select, and the chips come back after a relaunch. Every e2e spec and the walkthrough that typed into a retired control does it through a chip. UC-4, the rulebook, DEC-71 and the roadmap state what the build settled.
