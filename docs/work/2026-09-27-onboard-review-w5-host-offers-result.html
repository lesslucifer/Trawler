Distillation

Nothing to T2 in this WU: the epic plan gives UC-ONBOARD to W6. The sentences W6 has to add: a host is offered only the platforms that run beside it (the iOS Simulator on macOS only). A probe that cannot read says so, on every host, and "check again" shows only where a probe can answer. The network task names the address and the interface it arms, and a host with no address is told to join the device's network and read again. Where nothing observes a task, the open guide stays the first undone one (R10, Q3). Switching platform opens each guide as the new platform's rule says.
