E2 · doc-archive — archived docs leave git

T3 plan: move the archive out of git and make the epic gate enforce doc hygiene.

Draft v1 · 2026-07-05 · Trawler · T3 work doc · epic/doc-archive

Epic requirement

Archived work docs must not be tracked in git: archiving = distill, git rm the file, move it to docs/.archive/ (gitignored — git history keeps the content). The epic gate must verify that no unexpected docs stay tracked: at an epic tip the only tracked paths under docs/ are flat T1 files, docs/use-cases/ and docs/decisions/.

WU E2.W1 · wu/doc-archive/gate

Requirement. Replace the base-relative unarchived-work-doc check with an absolute expected-tracked-docs check at the epic gate; gitignore docs/.archive/; migrate the one tracked archive file (docs/work/archive/2026-07-05-workflow-brainstorm.html) out of git into docs/.archive/; update documentation-system.html, workflow.html and record the decision (DEC-3).

Design notes

The check is absolute (whole tree at the tip), not base-relative: main is migrated clean in this same epic, so any hit is real; a base-relative check fails open when junk lands on main through an ungated path. The archive action in doc/v1 now surfaces as a file deletion in the gated diff; the existing lineage check (distilled_to) keeps covering it. A work doc created and archived inside the same epic nets out of the epic diff — its lineage evidence lives at the WU seam that deleted it.
