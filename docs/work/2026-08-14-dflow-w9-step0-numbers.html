How the hard-predicate question was answered

An archived run is exempt from Tier-1 — that is what data-status="archived" buys. So the question "has this predicate ever gone red on a real artifact" cannot be asked of the tree as it stands. It is asked of a reopened scratch copy of each run: the flag is stripped, the run is fed to the same verify-doc the gate calls, and the reds are read off by slug.
