Follow-ups

WhatWhy not here
Fragment resolution — whether foo.html#bar's anchor exists in foo.html epic non-goal. The corpus links fragments into other docs in several places, so the predicate would have real work to do; it needs its own decision about what counts as an anchor (id, data-c, or both).
The epic's composed e2e — all four fixes in one gated merge on a synthetic repo owed at the epic close, not at this WU. W1–W3 each deferred their steps the same way; this WU shipped its step 3.
run_paths resolves a CLI path against the process's CWD when a same-named file happens to exist there, only falling back to the repo root otherwise — so a doc can be read, and its links resolved, from the wrong base pre-existing since E-PLAN.W2 and untouched by this diff; the review graded it a nit on that basis. The link check inherits the ambiguity rather than introducing it.
The pre-commit hook sources $HOME/.cargo/env, which a Homebrew rustup install does not create — every hook failed with cargo: command not found until one was written by hand, and it pins a Cellar version path that a brew upgrade will break environment, not this WU's diff. Filed so the next agent that hits it does not re-diagnose it.
