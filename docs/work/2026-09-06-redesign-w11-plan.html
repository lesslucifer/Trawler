What could go wrong

RiskHandling
The e2e is the first full run since W10's merge and touches five rebuilt screens at once. A red spec here is an epic-level finding, not a W11 one. Run it before writing any note. A failure is fixed on this branch and re-run — the epic cannot close on an unproven e2e, and a waiver would defeat the WU's only purpose.
Archiving docs/work/ breaks relative links: verify-doc reds any doc whose href no longer resolves, and T2 records cite the runs. Per the work-planning standard, an archived target is repaired by rewriting the citation as plain text marked archived — never by pointing into docs/.archive/. Every inbound link from T1/T2 is swept before the move.
Deleting Gallery.tsx falsifies a T2 record — DEC-25 names it among the eight product screens. It does not: that line is a dated measurement of what existed when the decision was taken, and decision records are append-only history. Judged, not assumed — and stated in the result so the next reader need not re-judge it.
