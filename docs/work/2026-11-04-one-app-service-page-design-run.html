Design run — the Capture service page

What Settings… shows about the process Trawler captures with: whether it runs, where it listens, what it logs, and the one thing a user can do about it, restart it.

Design run · round 1 on 2026-11-04, closed on the owner's LGTM · Trawler · T3 (docs/work/) · E-ONEAPP.W3 · branch wu/one-app/service-page · epic E-ONEAPP · WU plan · input: W2's contract, ui/src/coreService.ts

Mockup

Mounted from the real ui/src/components/. The frame is the Settings window, and the log tail is build-local (see Proposals). Each button shows one state. Read each one alone.

overflow: the window opens at the pane width and its own height. heading, state, facts and actions are bounded — one line each, and the facts are at most four rows. log is the only unbounded zone: it takes the window's remaining height and scrolls itself. Its rows are capped at the supervisor's ring (LOG_LINES, 2000 lines, owner: supervisor.rs), and a long line wraps. band is the main window's existing notice band, one line plus its action.
