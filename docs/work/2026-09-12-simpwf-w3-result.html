Deviations

Difference from the WU planWhy
The judgment is validated more than "the notes minus the derived fields": a layer needs a covers sentence, an entry's action must be one of added | updated | archived | deleted, and a tier that contradicts its path is refused the gate reads only archived among the actions and never reads a tier against anything but the path, so a typo in either would reach the merge as a silence. The refusals are this command's own (0·judgment) because they are facts about the input document
The count rule is a line rule over the file's text, stated with its limits rather than presented as the number of tests a file has the round found two real misses — an attribute written with arguments (#[tokio::test(flavor = …)]) and vitest's it.each/test.each tables — and both are counted now. What remains is stated in DEC-44: a declaration written in another form is not counted, and text that spells one is. A file that counts to zero is refused, so a miss is loud; a fixture that spells an attribute inflates the number, and the note names the files it measured
A diff the merge exempts is reported as exempt, not refused and not written for the round's finding: the gate returns before it reads a note for a docs/infra-only diff, so demanding one would be this command inventing work the workflow does not owe
The writer does not run the epic's tracked-doc check or the design checks those read the delivered tree, not the notes. Their repair is a commit, and DEC-44 draws the line by subject exactly as DEC-43 drew the preflight's
The rule-bearing T1 docs (docs/workflow.html) carry this WU's rule but need a human Reviewed-By trailer at commit time, so they are staged and committed by cargo xtask mr commit rather than by this session DEC-10: a rule-bearing doc is authorised by a listed human at commit time. The commits in §Evidence are the ones this session wrote; doc/v1 lists all of them

The review round

E-SIMPWF changes the review flow itself, so this epic's WUs are not put through the code-review skill: the owner ruled that the note records whatever review did run, waives it with a reason, and the human's mr/v1 sign-off is the review (epic plan). What ran here: five finders in fresh contexts — correctness, reuse, simplification, efficiency and altitude — over cb12f84..5928f84, with no adversarial verifier pass claimed and no design finder: cargo xtask design-scope reported no artifact in the range. The fixes landed in c367efc, which the finders did not see; that delta is the fixes below, read before PASS.
