E-PANELS.W3 — build: Splitter and useLayout

The list/pane split and the headers/body split become user-sized lines, restored at launch, saved on release, and reset all at once from View ▸ Reset Layout. The column handles are W4's.

v1 · 2026-11-03 · Trawler · T3 WU plan · E-PANELS.W3 · branch wu/panels/splitter · epic plan · built from the design run and the Splitter design · base cf09e4be

Requirement

The list/pane split and the headers/body split are each a Splitter the user drags or steps from the keyboard between their token bounds; the sizes are restored from the saved layout at launch, clamped to the live window without changing what is saved, written once per release, key step or reset, and View ▸ Reset Layout puts every size back to its default.

Mapping

E-PANELS · UC-4 (list/pane split) and UC-5 (headers/body split) · the epic's expected results 1, 2, 3, 5, 6, 7 · rulings Q6 (double-click resets one, an act resets all), Q7 (no collapse) · the design run's C1 (Reset Layout in the View menu), C2 (the share is a ceiling), C3 (pane-min wins), C5 (no reset key), C7 (the bounds) · DEC-67.
