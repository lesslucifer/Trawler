Outcome

Delivered as planned. Against the W2 requirement and its "done when":

  • Native install, Rust owns the command. ui/src-tauri/src/setup.rs — install_ca(pem) validates the PEM header, writes a temp .pem, builds the exact per-OS argv from a fixed template (install_command: macOS security add-trusted-cert … System.keychain · Windows certutil -addstore -f ROOT · else None) and wraps it in elevation (elevated_argv: osascript "with administrator privileges" / PowerShell Start-Process -Verb RunAs). The webview passes only the PEM, never a command. Registered as the app's first invoke_handler command.
  • System selector + guided steps everywhere. ui/src/setup.ts — hostOs() (UA family), canAutoInstall (mac/win only), guidedSteps(target) as plain-text data for all six targets (macOS/Windows/Linux/Firefox/iOS-Simulator/Android, incl. the Firefox-own-store and Simulator-uses-host notes). The selector defaults to the detected host; steps stay visible on the auto path and after any failure.
  • Step body wired, machine untouched. Onboarding.tsx's trust-ca body renders the selector, steps, and — only when selected == host && auto-capable — the Install certificate button with local idle/installing/done/failed state. App.tsx supplies installCa = api.caCertPem() (new GET /ca.crt client method) → invoke("install_ca", {pem}). done means only "the command exited 0"; nothing transitions the machine — W4's capture proves trust.
  • Gates green, headless. 43 vitest tests (7 files) · 6 cargo test units in the standalone src-tauri crate · clippy clean · cargo xtask ui build (tsc + vite) clean.

Deviations

  • install_ca is sync, not async. The plan sketched async fn; a Tauri sync command runs on a worker thread, which is the right place to block on an elevation prompt — an async command would park a runtime thread for the prompt's duration. Same IPC surface, same contract.
  • install_command(os: &str, …) instead of a HostOs enum. It takes std::env::consts::OS's string directly — one type fewer, the unit tests pin the identical argv output the plan's contract specified.
  • elevated_argv split out and unit-tested. The plan required builder tests only; keeping the elevation wrapper pure made it testable for free (osascript / UAC wrapping asserted).
  • Selector fallback: an undetectable host (other) defaults the selector to Linux rather than hiding it — every system's steps remain reachable.
