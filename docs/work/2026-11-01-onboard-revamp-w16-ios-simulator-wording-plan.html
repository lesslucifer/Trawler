Requirement

On the iOS Simulator, each state of the setup screen leads with the one thing to do next. That thing is a button wherever the shell can do the step itself, and its command stays as the other way. Every word names one thing one way and is true of what the screen read. No step asks for what nothing needs. The way back names the Simulator's own menu. What explains shows only on request (W13's R1). A test holds each rule.
