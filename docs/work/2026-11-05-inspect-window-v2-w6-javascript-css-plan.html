E-INSPWIN2.W6 — build: javascript and css

The data window gets real javascript and css surfaces: highlighted, searchable, and reformatted as one undoable working-copy step.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · branch wu/inspect-window-v2/javascript-css off epic/inspect-window-v2 at a44c3fac · epic plan: E-INSPWIN2 · design: W3's run (E5, E6)

Requirement

A data window holding JavaScript or CSS (named by its label or picked, never guessed from bytes) shows it highlighted with fold and find, and reformat (⋯, ⌥⇧F) expands it as one undoable working-copy step that marks it modified, keeping every token; when the formatter cannot honestly read the text the row is disabled and says why and the text is untouched; the formatter loads only inside the data window, when such a kind is on screen; restore original returns the exact bytes.
