Per-OS flows

Install and first open

flowchart LR

  V -- mismatch --> X[Delete, download again]
  V -- OK --> OS{System}
  OS -- macOS --> M1[Open .dmg, drag to Applications] --> M2[Open: macOS can't verify the app] --> M3[System Settings → Privacy & Security → Open Anyway] --> R

Trust the certificate on this machine

Another device

flowchart LR
  P[Pick a device] --> K{Kind}
  K -- iPhone or iPad / Android device --> A[1 Allow … to connect → Allow] --> C[2 install the certificate: scan the QR] --> W[3 set the Wi-Fi proxy] --> Q[4 Make a request]
  K -- iOS Simulator · macOS only --> SS[set up the Simulator: certificate in every running Simulator + this Mac's proxy] --> Q
  K -- Android emulator --> E[set up the emulator: certificate via adb + proxy 10.0.2.2] --> Q
Phones need the allow step; simulators and emulators reach Trawler on this machine. A Google Play emulator image has no root, so its certificate is installed by tapping through Settings.

Uninstall

flowchart LR
  A[Stop routing through Trawler] --> B[Remove the certificate] --> C[Turn off open Trawler at login] --> D[Quit Trawler] --> E[Remove the app] --> F[Delete the app folders]
  B -.-> B1[macOS · Windows: remove the certificate button]
  B -.-> B2[Linux: written steps]
  A -.-> A1[and on each phone or emulator: proxy off, profile / certificate removed]
Order matters: the proxy goes first (no internet without Trawler), the certificate before the app (its button lives in the app).

Draft 1 — Install

## Install

Download the file for your system from the
[latest release](https://github.com/lesslucifer/Trawler/releases/latest).

| System | File |
|---|---|
| macOS 11 or later (Apple Silicon and Intel) | `Trawler_<v>_universal.dmg` |
| Windows x64 | `Trawler_<v>_x64-setup.exe` (or the `.msi`) |
| Windows arm64 | `Trawler_<v>_arm64-setup.exe` (or the `.msi`) |
| Linux x64 | `.AppImage`, `.deb` or `.rpm` |
| Linux arm64 | `.AppImage`, `.deb` or `.rpm` |

Trawler isn't signed with a paid certificate. The first time you open it,
macOS and Windows warn that they don't know the publisher. Check your
download first, then follow the steps for your system. You do this once:
updates install from inside Trawler.

### Check your download

Download `SHA256SUMS` from the same release into the folder with your
file, then run:

- macOS: `shasum -a 256 -c SHA256SUMS --ignore-missing`
- Linux: `sha256sum -c SHA256SUMS --ignore-missing`
- Windows (PowerShell): `(Get-FileHash .\<file>).Hash`, then compare it
  with that file's line in `SHA256SUMS`.

Your file must say `OK`, or the two hashes must match. If they don't, the
download is damaged or was changed: delete it and download it again.

### macOS

1. Open the `.dmg` and drag **Trawler** to **Applications**.
2. Open Trawler from Applications. macOS says it can't verify the app.
   Click **Done**.
3. Open **System Settings → Privacy & Security**. Scroll down to the
   message about Trawler and click **Open Anyway**.
4. Click **Open Anyway** again and enter your password.

[S8]

### Windows

1. Run the `-setup.exe` (or the `.msi`).
2. If **Windows protected your PC** appears, click **More info**, then
   **Run anyway**.
3. Finish the installer, then open Trawler from the Start menu.

[S9]

### Linux

There's no prompt to get past.

- AppImage: `chmod +x Trawler_<v>_amd64.AppImage`, then run it. Keep the
  file where it is if you turn on **open Trawler at login**.
- `.deb`: `sudo apt install ./Trawler_<v>_amd64.deb`
- `.rpm`: `sudo dnf install ./Trawler-<v>-1.x86_64.rpm`

On GNOME, the tray icon needs the AppIndicator extension.

Next: [First run](#first-run).

Draft 2 — Trust the certificate

## Trust the certificate

To read HTTPS, Trawler decrypts it with its own certificate,
**Trawler Proxy CA**. Trawler makes it the first time it runs; it is
unique to your install. Your system decrypts nothing through Trawler until
it trusts that certificate, and it sends nothing to Trawler until its proxy
points there. The setup screen does both; it opens by itself until Trawler
has decrypted a request, and **⋮ → set up another device** opens it later.

Pick **This machine** in **which device's traffic do you want to see**.

[S2]

### macOS

Click **set up this Mac** and enter your password once. It trusts the
certificate for every user of this Mac and points this Mac's proxy at
Trawler.

To do it by hand, open **do it by hand** under each task:

1. Click **open in Keychain Access**. Search `Trawler`, double-click
   **Trawler Proxy CA** and set **Trust → When using this certificate →
   Always Trust**.
2. Close the window and enter your password.
3. Under the second task, click **open Proxy settings**, then **Wi-Fi →
   Details… → Proxies**. Turn on **Web proxy (HTTP)** and **Secure web
   proxy (HTTPS)**, each with server `127.0.0.1` and port `7420`. Click
   **OK**. On Ethernet, pick Ethernet in place of Wi-Fi.

### Windows

Click **set up this PC** and approve once. It trusts the certificate for
every user of this PC and points your account's proxy at Trawler.

To do it by hand:

1. Click **open the certificate**, then **Install Certificate… → Next**.
   Choose **Place all certificates in the following store → Browse… →
   Trusted Root Certification Authorities**, click **OK → Next → Finish**,
   and **Yes** on the warning.
2. Under the second task, click **open Proxy settings**, then **Manual
   proxy setup → Use a proxy server → Set up**. Turn on **Use a proxy
   server** with `127.0.0.1` and port `7420`, and click **Save**.

If nothing arrives, turn off **Automatically detect settings** and **Use
setup script** on the same page: either one outranks the proxy. Apps that
were already open may need a restart.

### Linux

Trawler can't change these for you on Linux. Each place below keeps its
own list of trusted certificates, so add it to the ones you use. The steps
are Ubuntu's; other systems name them differently.

1. Under the first task, click **save…** and keep `trawler-ca.pem` in
   Downloads.
2. Firefox: **Settings → Privacy and security → Connection and software
   security → Advanced settings → Manage certificates → Authorities →
   Import…**, choose `trawler-ca.pem`, tick **Trust this CA to identify
   websites** and click **OK**.
3. Chrome or Chromium: **Settings → Privacy and security → Security →
   Manage certificates → Local certificates → Installed by you → Trusted
   Certificates → Import** and choose `trawler-ca.pem`.
4. curl and the system's tools:
   `sudo cp "$(xdg-user-dir DOWNLOAD)/trawler-ca.pem" /usr/local/share/ca-certificates/trawler-ca.crt && sudo update-ca-certificates`
5. Under the second task, click **open Network settings**, then **Proxy →
   Network Proxy → Configuration → Manual**. Set **HTTP Proxy** and
   **HTTPS Proxy** to `127.0.0.1`, port `7420`, and click **Save**.
   Firefox and Chrome follow this proxy; terminal tools read `HTTPS_PROXY`
   instead.

### Check it worked

Click **make a request to example.com**. When it says **example.com
answered through Trawler.**, you're set. If it says **the request reached
Trawler and didn't decrypt.**, restart your browser: it reads the trusted
list when it starts.

While Trawler's certificate is trusted, anyone who can read your user files
could use its key to read your HTTPS. Remove it when you stop using
Trawler ([Uninstall](#uninstall)).

Draft 3 — Uninstall

## Uninstall

Do these in order. The first two need Trawler open.

1. **Stop the proxy.** On the setup screen, under the second task, click
   **stop routing through Trawler** (macOS and Windows). On Linux, run
   `gsettings set org.gnome.system.proxy mode 'none'`.
   Without this, your system has no internet once Trawler is gone.
2. **Remove the certificate** (below, per system).
3. **Turn off open Trawler at login** in **Settings… → General**.
4. **Quit Trawler**, then remove the app and its folders (below).

Did you capture a phone, a simulator or an emulator? Undo it there too
(below).

### macOS

1. On the setup screen, under the first task, click **remove the
   certificate** and enter your password.
2. Drag **Trawler** from Applications to the Bin.
3. Delete `~/Library/Application Support/dev.trawler.app`.

### Windows

1. On the setup screen, under the first task, click **remove the
   certificate** and approve once. If you added the certificate by hand,
   run in PowerShell instead:
   `certutil -user -delstore ROOT "Trawler Proxy CA"`
2. **Settings → Apps → Installed apps → Trawler → Uninstall.**
3. Delete `%APPDATA%\dev.trawler.app`.

### Linux

1. Firefox: **Manage certificates → Authorities → Trawler Proxy CA →
   Delete or Distrust…**
2. Chrome or Chromium: **Manage certificates → Local certificates →
   Installed by you → Trusted Certificates → Trawler Proxy CA**, delete it.
3. If you added it for the system's tools:
   `sudo rm /usr/local/share/ca-certificates/trawler-ca.crt && sudo update-ca-certificates --fresh`
4. Remove the app: delete the AppImage, or `sudo apt remove trawler`,
   or `sudo dnf remove trawler`.
5. Delete `~/.local/share/dev.trawler.app` and `~/.config/dev.trawler.app`.

### Phones and simulators

| Device | Proxy off | Certificate |
|---|---|---|
| iPhone or iPad | **Settings → Wi-Fi → ⓘ → Configure Proxy → Off → Save** | **Settings → General → VPN & Device Management → Trawler Proxy CA → Remove Profile** |
| Android device | **Settings → Network & internet → Internet → ⚙ → ✎ → Advanced options → Proxy → None → Save** | **Settings → search Trusted credentials → User → Trawler Proxy CA → Uninstall → OK** |
| iOS Simulator | follows this Mac (step 1) | **Device → Erase All Content and Settings** (erases everything in it) |
| Android emulator | setup screen: **stop routing the emulator** | **Trusted credentials → Trawler Proxy CA → Uninstall → OK** |
