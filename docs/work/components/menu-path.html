MenuPath

The controls a step clicks through, each name set apart from the sentence that leads to it.

Component design · 2026-10-31 · Trawler · proposed by the setup design run, round 20 (E-ONBRVP.W12, D2) · drawn in context there · retires into the TSDoc on build (DEC-16)

Why this exists

In body text, a path reads as prose. In In Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, a reader looking for the button cannot tell where the sentence ends and the control names begin. The reels showed it as two grey lines (W12's D2).

DriverDesign consequence
The user matches each name against a windowEach name is set in text-ink, a step above the sentence's text-ink-body. The UI has one weight, so ink does the work
A name is a label, not wire dataNot mono (mono-for-wire-data), and not copyable
The arrows already carry the order (D2: "the arrows stay")→ between names, in text-ink-mute
Long paths wrap in a narrow columnA line breaks between names, never inside one
W13–W19 reuse it for every Settings pathA step part of its own in setup.ts ({ path: string[] }), as a value and a command already are

The contract

FacetDecision
tierT1: props in, a span out, with no state.
anatomyAn inline-flex, wrapping span with gap-x-chrome-gap. Each name is a whitespace-nowrap span in text-ink, with → in text-ink-mute between names. Size and family are inherited from the sentence.
one nameAllowed: Double-click Trawler Proxy CA. It is still a control the user looks for.
accessible nameNone of its own. The text reads in order, and a screen reader says the arrows.
statesOne. It is text.

Forks

settled: ink names, mute arrows

A tone step inside the sentence's own type, with nothing new in the vocabulary.

rejected: each name in a chip

Chips read as buttons in this UI, and a path is not clickable.

rejected: mono

Mono means wire data: what is copied or typed. A menu name is looked for, not typed.

rejected: a numbered sub-list

It turns one step into six and breaks the guide's numbering, which counts the user's acts.

Use and avoid

Use

Inside a guide's step, for the controls the user clicks through in another app or in Settings.

Avoid

A file path or a value, which is CopyText · a command, which is CommandBlock · Trawler's own controls, which are on screen.

Callers at build

Every → path in This machine's guides (round 20): Keychain Access, the macOS proxies, Windows' proxy and installer, GNOME's Network, and Firefox's Authorities. W13–W19 move the other platforms' paths onto it.
