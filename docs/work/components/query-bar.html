QueryBar T2

One box of filter chips and a draft. Typing writes the draft, suggestions follow it, and a chip is made only when the draft parses.

Component design · 2026-11-04 · Trawler · status: confirmed 2026-11-04 (round 1; C1 took the alternative: Enter takes the highlight) · proposed by the query bar's design run (E-QUERY.W2) · built by E-QUERY.W3 · retires into the TSDoc on build (DEC-16)

Identity & frame

Without it the header keeps four controls with four rules, two filters stay unreachable, and a typed filter has nowhere to say it is wrong except an empty list.

FactValue

States

rest, empty
rest, with chips (keyed, repeated, negated, text)
a chip refused by the core
chips wrapping in a narrow bar

Focused, suggesting, moved and faulted are live states: the specimen at the end shows each. Not states: disabled (the list can always be filtered), loading (suggestions are local), restored (a restored chip is a chip), a chip being edited (C9).

/**
 * QueryBar — one box of filter chips and a draft; suggestions follow the draft, and a chip is made only when the draft parses.
 * @tier T2 — owns the grammar (draft → chip or fault, draft → suggestions) through query.ts; chips, hosts seen and the refusal are the caller's
 * @anatomy Field's box, flex-wrap, chrome-tight padding · chips: wash-tint pill, mono, key and "-" ink-mute, value ink (MethodLabel for a method), IconButton × size 24 · refused: warn border + ⚠ · draft: borderless mono input, min-w-field-sm · suggestions: Select's popup surface under the draft, completion mono + hint ui + the key that takes it · fault: an inline warn Notice in the suggestions' place
 * @use the one filter of a list the user narrows by typed keys and text: the flow list's header
 * @avoid one free-text value (Field) · one choice among options (Select) · actions or commands in the bar (DEC-71 rule 9) · calling the caller on a keystroke: onChange is for chips only · editing a chip in place
 * @states rest · focused (suggestions, Enter or Tab takes the highlight, Space the draft as typed) · moved (↑/↓ highlight) · faulted (warn Notice until the next keystroke) · chips · a refused chip. No disabled, loading or restored state
 * @madeof IconButton · MethodLabel · Notice
 */

Use / avoid

Use

A list narrowed by several typed filters at once, where each filter is a key and a value, or text, and the list should move only on a finished filter.

Avoid

One free-text value (Field) · one choice among known options (Select, or SegmentedControl under five) · actions in the bar (they stay in the menus).
