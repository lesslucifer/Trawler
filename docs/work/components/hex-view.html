HexView T2

The whole hex dump of a binary payload, virtualised, read-only, with find marks that cross row boundaries and a byte range that copies.

Component design · 2026-11-03 · Trawler · status: draft, awaiting confirmation · proposed by the data window's design run (E-INSPWIN.W2) · built by E-INSPWIN.W3, extended by W5 · retires into the TSDoc on build (DEC-16)

Identity & frame

Without it a binary payload stops at 4 KiB, HexRenderer's cap, and the window could not show the one kind with no other way to read it.

/**
 * HexView — the whole hex dump of a payload in the data window, virtualised and read-only, with byte-range find marks and a copyable selection.
 * @tier T2 — owns the dump layout (offset · 16 bytes · ASCII) and the range selection; the bytes and the match ranges are the caller's
 * @anatomy offset ink-mute · 16 bytes ink-body, wider gap after the 8th · ASCII, non-printable as ink-mute "." · matched bytes wash-select + ink in both columns, current wash-active · selection wash-select in both columns
 * @use the data window's hex surface (DEC-68): a binary payload, or any payload the user views as hex
 * @avoid the body pane (HexRenderer, capped at HEX_MAX by contract) · editing bytes · a cut marker or any cap
 * @states rest · with find marks · with a selected range. No editable, empty or loading state
 * @madeof @tanstack/react-virtual (T0)
 */

Use / avoid

Use

The data window, for bytes that are not text, or any payload viewed as hex.

Avoid

The pane (HexRenderer) · a decoded result in the decoder panel (HexRenderer is enough, capped, with open in data window as its way past).
