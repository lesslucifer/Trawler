StepMedia

The recording a by-hand step carries under its sentence, where a screen opens and the user must still find the control.

Component design · 2026-10-31 · Trawler · proposed by the setup design run, round 20 (E-ONBRVP.W12, M1) · drawn in context there · retires into the TSDoc on build (DEC-16)

Why this exists

A route can open the right screen, but it cannot click the control on it. Without media, a step like Trust → When using this certificate → Always Trust is a sentence the user must map to a window they have never seen. With it, they see the control first and then find it.

DriverDesign consequence
The epic's Q11: interactive first, media where no route can finishMedia only under a step whose route has stopped. Never in place of a route
The sentence is the instruction (UC-ONBOARD)The step reads whole without it. A missing or failed recording takes nothing from the step
Recordings age with the OS they showEach one names the OS version it shows, under it
Setup runs offline and hermeticThe file ships in the app bundle. A URL from the network is never accepted
motion-informs · WCAG 2.2.2A video moves only to show the clicks. It can always be paused, and does not start under reduced motion

The contract

FacetDecision
tierT1: props in, a figure out. Its only state is the video element's.
anatomyA figure below the step's sentence. The media is full width up to max-w-pane at its own aspect, in a rounded-card frame with a border-hairline border. Below it, a one-line caption in text-chrome text-ink-mute naming the OS version it shows (macOS 26).
kindsimage: one still, for a control that is visible once the screen opens. video: a short clip, at most 15 s, muted and looped, for a sequence of clicks. It plays inline with native controls and starts on mount, except under prefers-reduced-motion: reduce, where it waits on its first frame.
accessible namealt is required. It names the path the media shows, in the step's own words (Keychain Access: Trawler Proxy CA → Trust → Always Trust). A video carries it as aria-label.
failureA file that does not load renders nothing, caption included. The sentence above it is the step.
sourceAn asset imported from ui/src/assets/setup/, so the bundler fingerprints it. A video takes an mp4 (H.264) and a webm (VP9) source, so that WKWebView, WebView2 and WebKitGTK each play one.
colour · type · spacingNothing of its own: hairline, ink-mute, chrome type, gap-chrome-tight between media and caption.

States

StateShows
imagethe still and its caption
video, motion allowedplaying on a loop, controls on hover and focus, caption
video, reduced motionits first frame with controls, until played
failed to loadnothing

Not a state: empty. A step with no recording renders no figure, because the caller passes no media.

Forks

settled: video with two sources

Pausable, with native controls everywhere, and small at 15 s. Two sources cover each webview's codecs.

rejected: animated WebP or APNG

It plays in every webview but cannot be paused (WCAG 2.2.2), ignores reduced motion, and is several times the size of a video for the same clip.

rejected: a link to a hosted video

Setup must work offline. A remote URL is also the one thing the shell's route command refuses to open.

rejected: media in place of the sentence

The sentence is searchable and copyable, and a screen reader reads it. The recording only shows it.

Use and avoid

Use

Under the step of a by-hand guide whose button opened a screen, where the next control is a click or more away and its name alone does not find it.

Avoid

As the step's instruction · beside a command, whose block already is the step · where a route opens the control itself · decoration (motion-informs).
