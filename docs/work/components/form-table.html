FormTable T2

Every pair of a URL-encoded form, uncapped, each key and value whole and wrapped, edited in place.

Component design · 2026-11-03 · Trawler · status: draft, awaiting confirmation · proposed by the data window's design run (E-INSPWIN.W2) · built by E-INSPWIN.W3, extended by W5 · retires into the TSDoc on build (DEC-16)

Identity & frame

Without it a 300 KiB form is cut at 128 KiB by FormRenderer, squeezed into a 520 px grid, and cannot be changed at all, so the window would show less of a form than of any other kind.

States

Not states: empty (a form with no pairs is the screen's none) · collapsed or clamped values (never, so no more link) · an edited look (DEC-59: the screen says modified).

/**
 * FormTable — every pair of a URL-encoded form, uncapped, each key and value whole and wrapped, edited in place.
 * @tier T2 — owns display decoding, the duplicate-key count and the never-cut rule; the pairs, their order and what an edit means are the caller's
 * @anatomy sticky uppercase-mute label row (# · key · value) · number ink-mute · key mono syn-key, "N of M “key”" under a repeat · value mono ink, wrapped whole, "none" when empty, "kept as sent" under a bad escape · IconButton close per row · selected row canvas-soft · the edited cell a multiline verbatim Field
 * @use the data window's form surface, decoded (DEC-68)
 * @avoid the body pane (FormRenderer, capped and read-only) · truncating, clamping or fixing a row's height (DEC-34's escape is not taken here) · re-encoding pairs nobody edited · sorting or filtering inside it: the caller hands the order and the rows
 * @states rest · selected row · editing one cell · read-only (a view) · with find marks. No empty, collapsed or loading state
 * @madeof Field (T1) — the edited cell · IconButton (T1) — remove · @tanstack/react-virtual (T0)
 */

Use / avoid

Use

The data window's surface for a form payload shown decoded.

Avoid

The pane (FormRenderer) · headers (KeyValueRow) · the form shown encoded (EditSurface, plain).
