ChipBox T1

One box of typed chips and a draft. The draft becomes a chip when it parses, suggestions follow it, a fault says why it did not, and a chip the caller refuses is marked. What a draft means is the grammar the caller hands in.

Component design · 2026-11-05 · Trawler · status: confirmed by the owner 2026-11-05 · proposed by the data window's kinds and find design run (E-INSPWIN2.W3) · built by E-INSPWIN2.W8 · extracted from QueryBar (DEC-71) under the epic's Q12 · retires into the TSDoc on build (DEC-16)

Identity & frame

Without it, the data window's find would either copy QueryBar's box — and drift from it the first time one of them changes — or widen QueryBar into a component that owns two grammars. ChipBox is the box both are made of, with the grammar left to each.

Use / avoid

Use

QueryBar's box and the data window's find bar: anywhere a user types keys and text that become chips.

Avoid

One free-text value (Field) · a pick from a list (Select) · a box that owns what its chips mean.
