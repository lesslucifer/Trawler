States

MethodLabel is value-variant, not interaction-variant. The "states" are the full set of HTTP methods it must render, each resolved through the verb→color mapping — five scan-target verbs carry a color token, the rest fall back to body tone. There is no hover, focus, or click state — the component is text.

Deliberate non-states: no hover, no focus, no active. MethodLabel is display-only text — there is nothing to interact with. The list row owns the hover highlight (FlowList.tsx:70 hover:bg-canvas-soft); the method label rides that row state passively. A focus ring or cursor change on a non-interactive element would confuse keyboard users.
Non-standard method: any verb not in the mapping (e.g. PURGE, BREW) renders in the fallback body tone with the same fixed-width rule — a static map cannot know it, and inventing a color per unknown verb would defeat the mapping's scan value. The slot may overflow for very long verbs — that is intentional (never truncate a method name).

Settled: per-verb color coding — manager decision on review, taking the promotion path this fork had reserved: an explicit T2 with named tokens, never an ad-hoc tint. The familiar Postman/Insomnia convention: five scan-target verbs get tokens (GET #4cc38a · POST #e5bf4d · PUT #e5924d · DELETE #e5484d · PATCH #a78bfa); HEAD/OPTIONS/CONNECT/TRACE and non-standard verbs stay body tone — plumbing verbs add noise, not scan value. Method tokens join ok/warn as named DEC-11 chromatic exceptions (token map below). GET shares the ok hue and DELETE the warn hue deliberately — same semantic family (safe vs destructive); column position disambiguates method from status.

The original W2 draft settled no-color to protect DEC-11's zero-accent calm (tailwind.config.js:3) and keep status ok/warn the only chromatic signal. Superseded: the verb is a primary scan target and color makes it pre-attentive — the DEC-11 exception set widens with named method tokens instead of being breached ad hoc. The five-verb cap (not all nine) is what keeps the flag-parade risk contained.

D2 · fixed-width mechanism settled: ch-unit min-width on the component
GET OPTIONS

ch-unit min-width on the component span. The list grid column (70px in FlowList.tsx:9) already handles column alignment in the list — but the identity bar and any future context are not grid columns. A min-width: 4.5ch on the component guarantees the verb never causes a layout shift in any parent. The ch unit tracks the mono font so the slot self-calibrates if the font stack changes.

alt: rely solely on the grid column rejected — not portable

The list column does the alignment today (FlowList.tsx:9). But the detail identity bar (FlowDetail.tsx:62) is a flex row — no grid. A bare <span> in a flex row gives different widths per method, so the bar wiggles when navigating between flows. The fix must live in the component, not each caller.

alt: fixed px width rejected

A hardcoded px value (e.g. 52px) would break if the mono font stack changes or if the base font size is adjusted. ch units self-calibrate; px units don't.

D3 · fallback tone for unmapped verbs: body vs mute settled: body tone (ink-body)
OPTIONS body: #c9c0ad — reads clearly, slightly below ink

Body tone for verbs outside the color mapping (HEAD, OPTIONS, CONNECT, TRACE, non-standard). The method is data — a primary field in the row even without a token. Mute tone is reserved for metadata (timestamp, duration) per the shipped FlowList.tsx:79,86 pattern.

alt: mute tone (ink-mute) rejected
OPTIONS mute: #aea69c — recedes too far; method loses prominence

Mute reads as secondary — an unmapped verb would look demoted next to a colored one, as if the proxy trusted it less. Timestamp and duration are muted because they support the row; the method identifies it.

Use / avoid

✅ Use

Any place a flow's HTTP method must appear: the virtualized list rows (FlowList.tsx col 2), the detail identity bar (FlowDetail.tsx header). The component owns the uppercase transform, the fixed-width contract, and the verb→color mapping — callers pass raw.

🚫 Avoid

Do not restyle a verb at the call site — the verb→color mapping lives inside MethodLabel; a new or changed color is a token + mapping change here, never an inline tint (DEC-11 exceptions are token-named). Do not use for a non-method label just because it shares the visual style; reach for a plain font-mono text-ink-body span instead, and promote only when reuse evidence appears.
