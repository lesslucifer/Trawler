The code review binds the code paths it judged — cr/v4, a docs-only commit can no longer void a PASS, and a diff that changes no code owes no review. The design dimension left for a step of its own, on design/v1, which 9·design reads.

Outcome

The rule the epic lands outright is in the tree and in the gate. A review note is cr/v4 and its diff_sha256 is the hash of git diff BASE..HEAD -- <the code paths>; the note is demanded only when the diff touches a code path; the design verdict travels as design/v1 on refs/notes/design, written by a design step of its own and read by 9·design and nothing else. The five code rubrics, the severities and the adversarial verifier are untouched.

The review round

One round, on the owner's ruling for this epic: E-SIMPWF changes the review flow itself, so its WUs are not put through the fleet, and the tip carries a cr/v4 note recording what the round found and waiving it with a reason. The round read the code diff — the binding, the carrier switch, the demand rules and the preflight — and found one thing that mattered.

FindingDisposition
Important — one reader had not moved. components·unbuilt still read design.dropped off the review note, so an epic that recorded a drop on the note the verdict now travels on would have been refused for having recorded it Fixed in 11e6c21: the drop record goes through the same design_source as the verdict, and a drop-only design/v1 note parses — the fields a citation-only note omits are optional, exactly as the cr/v3 section's verdict already was. Test: an_epic_drop_record_is_read_from_the_design_note, which reds without the fix
Nit — the older schemas stay accepted. A new tip may still declare cr/v3 and carry its design section on the review note Recorded and waived in the note: cr/v2 and cr/v3 are read where a tip shipped one so every merged seam keeps its verdict, and the standard, the writer and the skill now name cr/v4. Retiring them is a deliberate later cut, not a hole in this rule
Nit — design_sha256 covers the endpoint diff's design paths. A design authored and retired inside one WU contributes no bytes to that hash Recorded and waived: that is the case the retired-design machinery already owns (DEC-29) — the bytes are read at their last state, pinned by the citation's blob — and the old whole-diff binding could not show them either

Verdict: PASS, with both nits dispositioned — recorded, and waived with the reason above, in the cr/v4 note on the tip.
