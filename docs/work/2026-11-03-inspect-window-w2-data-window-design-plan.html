E-INSPWIN.W2: the data window's design run

One closed design run for the data window, plus one component design for each registry component it proposes. W3–W6 build from these by blob. Nothing under ui/src/ changes.

v1 · 2026-11-03 · Trawler · T3 WU plan · E-INSPWIN.W2 · branch wu/inspect-window/data-window-design · epic plan · base 8bbb9418 · depends on W1 (DEC-68)

Requirement

W2 delivers one design run at docs/work/2026-11-03-data-window-design-run.html and a component design under docs/work/components/ for each registry component it proposes. The run mounts the real collection around a stateful data window: the six kinds and the override, original / working copy, the find bar, a ⋯ menu and a right-click menu holding each kind's acts, the status bar with the kind picker and the modified marker, the decode peek, the long-form table, and the empty and undecodable states. It also draws the entry point on BodyViewer and CutMarker. The owner reviews it. It is closed in three steps (review · green · data-status="archived"), and a design/v1 note on the tip names every artifact.
