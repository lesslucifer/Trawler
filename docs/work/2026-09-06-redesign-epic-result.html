Every shipped screen went through the design flow, and every build cites the design it was built from. The first design → build handoff in the repo's history.

Outcome

Delivered. The epic's intent was to run E-DFLOW's design flow on the five screens that predate it and execute the design → build handoff for the first time. All five went through; every rendered file is cited to a design or declared with a reason; the registry is the app's vocabulary rather than the scratch screen's. Deviations

Where the epic divergedWhy
Five planned design runs became four. The flow list and the app shell are one screen to a user and share the shell's zoning, so they were designed together — as the plan itself specified for W3. The count in the expected-result list was never adjusted to match its own WU table.
W2 did W4's and W11's work. Fixing a review finding required migrating three screens off the legacy kit and deleting it, before W3's design run existed. The alternative was shipping a WU whose deliverable the app could not reach. The layout was untouched, so W3 still designed the same surface — but the ordering the epic's own shape depends on was broken once, and W2's result carries the account.
A fourth registry entry (Checkbox) with no design file. Design run #9 ruled it out of scope; W10's author built it anyway so the dialog's remote mode landed complete. Recorded as a drop with its reason: it has a roster entry and the full six-tag TSDoc, so nothing is unbuilt, and a design file written now would be born retired under DEC-16.
Two design WUs closed without a result report. W3's mr/v1 attests its design run and W9's attests its plan doc — neither names a WU result report, which DoD-W requires. The epic gate does not catch this: check 8 is boundary-only and the walk does not re-judge mr at seams. It is recorded rather than repaired, because amending those tips would orphan their notes. A real gap in the record, and the first thing a reader of this epic's evidence should know.
The epic amended its own inputs twice. The plan named the flow, rulebook and gate as frozen inputs. Two rulebook amendments landed anyway — the wrap-not-truncate clause (DEC-34) and the chromatic-meanings row (DEC-30's consequence). Both are rulebook content, which DEC-14 provides for at distillation, and both were escalated to the close by the runs that found them rather than taken mid-run.
