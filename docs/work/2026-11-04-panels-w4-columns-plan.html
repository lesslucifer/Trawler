E-PANELS.W4 — build: column widths

The five fixed flow-list columns become user-sized from handles in the label row, saved and reset with the rest of the layout; the label row scrolls sideways with the rows.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-PANELS.W4 · branch wu/panels/columns · epic plan · built from the design run and Splitter's TSDoc (DEC-68) · base 9cc6ac01

Requirement

Each of the flow list's five fixed columns (time, method, host, status, duration) is sized by a Splitter on its boundary in the label row, dragged or stepped between its own token bounds while the path keeps at least path-min; the label row and every row read one grid template and scroll sideways together; widths are restored, saved and reset through the same useLayout as the splits, and a wider column lowers splitter A's live maximum.

Mapping

E-PANELS · UC-4 (flow-list columns) · the epic's expected results 2a, 4, 5, 6, 7 · rulings Q5 (columns are in scope), Q8 (labels scroll with the rows), Q9 (widths only) · the design run's C3 (a wide column lowers splitter A's max), C4 (ticks visible at rest), C5 (no reset key), C6 (rename columns.size → duration), C7 (the bounds) · DEC-67 · DEC-68.
