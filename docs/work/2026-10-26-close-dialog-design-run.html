Mockup

Mounted from the real ui/src/components/; the frame is ModalShell, build-local. Each button below shows the dialog for one reading — read each one alone.

overflow: the panel is capped at dialog-max wide and at the window's height. title, stake, outcome, opt-out and answers are bounded — each one sentence or one row. steps is the only unbounded zone: a command wraps (CommandBlock's own wrap) and the step count is the platform's; where the panel would pass the window's height the panel scrolls, the scrim never does (owner: this dialog).

Payload is mono and copies whole: the proxy-off command, such as gsettings set org.gnome.system.proxy mode 'none'. Nothing else in the dialog is read verbatim.
