What the backlog gains

from W4 · W6 — new

The shell has no valid arrangement below 1132px

path = window − pane − 612. With the pane open the row's fixed tracks overflow, and tauri.conf.json declares a minimum of 800. Widening the pane moved the threshold from 992 to 1132 — the epic made a known defect wider, deliberately and with the arithmetic published, because both fixes (the row's column widths, a second arrangement of the whole screen) are inside this epic's declared non-goals.

from E-REDESIGN — inherited

Tier-1 is blind to a mockup's mounted JSX

The tokenizer treats <script type="text/babel"> as opaque, and the flow requires the mockup to mount from exactly such a block. W4 met the consequence: six empty mounts, no console error, verify-doc green over markup it never read.

from E-REDESIGN — inherited

Gate check 8 does not check the report's type

It verifies that some report was attested, not that it is a result report. Both this row and the one beside it are xtask work, and changing the gate while it judges this epic's own seams is what E-REDESIGN's non-goals forbade.

from W6 — new, small

WebdriverIO's *= selector matches nothing here, silently

Against the embedded WebKit provider it never matches and never errors — three e2e runs failed on a screen that was rendering correctly. Worked around with a data-testid; worth a row so the next spec author pays the cost once.
