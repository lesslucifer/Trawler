Distillation

Nothing citable. W1 changes no product behaviour and no contract. The walkthrough is test support, and the command is named in cargo xtask's usage. UC-ONBOARD and the new DEC are W6's distillation, per the epic plan.

Follow-ups

  • W5: the scenario maps an unreadable proxy to today's absence (read_proxy(None, …)). When W5 gives the reader a "cannot read" answer, it changes that mapping in scenario.rs in the same commit, or the after recording shows R19 unfixed.
  • W2–W5: each fix keeps the anchors painting. A chapter anchors on test ids and on button-text prefixes ("Allow devices on my", "Set up this", "stop routing through Trawler"). A fix that renames or removes one extends that chapter's anchor list rather than dropping the chapter.
  • W6: re-run cargo xtask ui walkthrough for the after, and keep the before target/walkthrough/ by copying it aside first, since the command starts from an empty directory.
  • The last frame of each reel lingers 5 s past its caption, a side effect of the concat demuxer needing the last frame listed twice.
  • tsc -p ui/e2e does not resolve its type libraries. This predates the WU; tsx's runtime load is the check the walkthrough gets.
