Requirement

The inspector's pretty body and the data window pick their kind from readKind(bytes, served type) — bytes first, the label a hint — so JSON served as text/plain renders as JSON and HTML served as application/octet-stream opens as html while text that merely starts with { stays text; the pane states JSON · served as text/plain whenever the bytes overrule the label, the window's status bar says what decided the kind, the kind picker offers all nine kinds, and raw mode is unchanged.
