E-INSPWIN.W4 — JSON tools

The data window's JSON toolset on the surface W3 built whole: find, indent and sort keys as working-copy steps, fold to a depth, and copy a node's path or value.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-INSPWIN.W4 · branch wu/inspect-window/json-tools · epic plan · builds the design run

Requirement

On a JSON working copy the data window finds (a count, N of M, stepping by key) over the whole document; re-indents (2 · 4 · tab · minified) and sorts keys as undoable named steps that keep every value verbatim — numbers past 253, duplicate keys and string escapes included — and, on a copy that does not parse, say where instead of failing; folds to a depth from ⋯; and copies the path or the value of the node under a right-click or the cursor.

Mapping

E-INSPWIN · UC-9 JSON rows · epic expected rows 4 (find) and 5 (reformat) · builds the run's local FindBar, the glyphs previous and next, the ⋯ JSON section (indent, sort keys, fold to) and the not valid JSON notice · copy the path and copy the value on the right-click: the epic's toolset row, which the run did not draw, placed by the owner on 2026-11-04.
