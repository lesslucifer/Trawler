Requirement

cargo xtask vikunja check reads git worktree list --porcelain and every project-3 task's Branch: line, prints one JSON line per epic/* or wu/* worktree no task names (orphan) and per open task whose branch has no worktree (missing-worktree), and exits 1 if it printed any, 0 otherwise; router-agent and trawler-router make Vikunja the owner surface — task before branch, the ask/answer lifecycle of vikunja-protocol.md, and the Vikunja server, the webhook listener and vikunja check held by every heartbeat tick.
