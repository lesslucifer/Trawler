Deviations

What changedWhy
The leg switch left the pane. The plan — and the epic plan's W7 row — scoped this run around "a raw/decoded toggle and a leg switch", and both shape decisions taken up front kept leg as a SegmentedControl in the control row. The closed run instead designs a pane that renders one body, taking the leg as a prop, with the panel mounting one instance per leg. Raised in review on the Layout stage. It is correct and the run was wrong: FlowDetail.tsx already renders Request headers and Response headers as separate sections, so a single Body section switching legs inside itself stated the same fact a second way — a grouping-by-relatedness break the first draft missed by taking the shipped pane's shape as given. Every stage moved: Frame gained a constraint and lost a Given, Layout dropped zone A to one chooser, Elements resolves one SegmentedControl instead of two, Interaction traded see the other leg for compare the two legs.
A blocked-on entry was answered, not carried. The plan expected the leg-switch question to go to W5 as a considered fork. It is now settled here, and the blocked-on list carries the narrower question that remains. The same review. What W5 still owns is where the two body sections sit in the panel; the pane is leg-agnostic under every arrangement, so this run is not blocked on that answer.
One Tune call was replaced. The first pass proposed rewording CutMarker's sentence and filed a blocked-on entry against it. False finding, caught by rendering the mockup: the component already says "— save to see all", and its @anatomy already promises "the way out". That is the flow's never re-decide what a component owns failure. Replaced with a real screen-owned call — the marker rides in B's scroll flow, so on a capped body the one line whose job is to be seen is the first thing hidden; it is now pinned to B's foot, and that loops back to Layout.
The epic plan's W7 block and this WU's plan were both corrected — the epic block drops "and a leg switch" and names the outcome; the plan's superseded shape decision is struck through with a forward link here. Same rule W2 followed when its scope moved, and at both levels as W2 did it — its epic block gained a "Grew at review" note and its WU plan's voided waiver was struck through rather than deleted. A plan still asserting a control the design removed would mislead anyone reading it alone.
