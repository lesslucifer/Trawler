The data window gets an html kind of its own: highlighted source with re-indent, and a read-only preview of the working copy that runs no script and loads nothing.

Requirement

A data window holding HTML shows its source highlighted with fold, find and re-indent (⋯, ⌥⇧F, one undoable working-copy step), and a preview (status-bar switch, ⋯ choice, ⇧⌘V) that renders the working copy in an empty-sandbox frame behind a CSP that allows no request, with meta refresh and base removed and links inert: no script runs, nothing loads, nothing navigates; the preview is read-only and follows the working copy.
