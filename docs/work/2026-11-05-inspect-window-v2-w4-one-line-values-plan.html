E-INSPWIN2.W4 — build: one-line values and their openers

The inspector's header values and URI on one line, cut with an end ellipsis, and the two ways to open them whole in a data window, built from W2's closed run.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · branch wu/inspect-window-v2/one-line-values off epic/inspect-window-v2 at 8dd19f05 · epic plan: E-INSPWIN2 · design: W2's run (D1–D4, D6, D7)

Requirement

In the inspector every header value and the URI sit on one line, cut at the end with an ellipsis and copied whole on a click; the three-line clamp and more / less are gone; ↗ at the end of the URI line opens the whole URI, ↗ open all in the Headers heading opens the leg's headers as Name: value lines in wire order, and ⌘⇧O does either from where focus is; a leg with no headers offers no open all, and no header row carries an opener of its own.
