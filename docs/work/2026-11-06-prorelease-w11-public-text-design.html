Voice and tone

Plain

Short sentences, everyday words. A term a user won't know gets a gloss once ("certificate (CA)").

To you

Second person, present tense, active voice. No "we" in user text; Trawler is "Trawler" or "it".

Step, not theory

Say what to click, exactly as the OS labels it, in bold. Why comes after, in one line, if at all.

Honest

Limits are stated where they bite, not hidden. Never claim what the code can't show (see Facts).

Calm

No hype: no "best-in-class", "blazing", "100×", emojis in prose, exclamation marks, user counts or awards.

No futures

No "coming soon", dates or roadmap promises in public text. What ships is what's described.

FAQ

QuestionAnswer (draft)
Is it free?Yes. MIT licence, no paid tier, no account.
Why does my computer warn me when I first open it?Trawler isn't signed with a paid certificate. The warning is the OS saying it doesn't know the publisher. Check your download against SHA256SUMS, then follow the steps in Install.
Is it safe to trust Trawler's certificate?The certificate is made on your machine and is unique to your install. While it's trusted, anyone who can read your user files could use its key to read your HTTPS. Remove it when you stop using Trawler (GUIDE → Uninstall).
Does Trawler send my traffic anywhere?No. It forwards each request to where it was going and keeps a copy in memory on your machine. See PRIVACY.
Where are captured requests saved?Nowhere: they live in memory and go away when you quit. Export to HAR to keep them.
Why don't I see an app's traffic?The app ignores the system proxy, pins its own certificates, or uses HTTP/3. See Known limits.
Can I capture my phone, a simulator or an emulator?Yes: iPhone, Android, the iOS Simulator and the Android emulator, from the setup screen.
How do updates work?Trawler checks GitHub when it starts (at most once a day) and when you choose Check for Updates…. It asks before installing, and only installs a release signed by the project.
How is it different from Charles, Proxyman, mitmproxy or HTTP Toolkit?Trawler is native on all three desktops, open source and local-only. It doesn't have breakpoints, rewrite rules or scripting yet.
Can I script it?Yes: a local HTTP API on 127.0.0.1:7421 lists, streams, exports and replays requests (CONTRIBUTING → API).
How do I remove it completely?Remove the app, the certificate's trust and the app data folder (GUIDE → Uninstall).

Privacy statement — draft (PRIVACY.md)

Trawler keeps your traffic on your machine. It has no account, no analytics, no crash reporting and no telemetry.

WhatWhere it goes
Requests you captureMemory only, on your machine. Gone when you quit. Saved to a file only when you export HAR.
Trawler's certificate and its private keyYour app data folder, unencrypted: ~/Library/Application Support/dev.trawler.app/ca (macOS) · %APPDATA%\dev.trawler.app\ca (Windows) · ~/.local/share/dev.trawler.app/ca (Linux). Never sent anywhere.
Settings and window layoutYour app config folder. Never sent anywhere.
Update checkA request to GitHub when Trawler starts (at most once a day) and when you choose Check for Updates…. GitHub sees your IP address and Trawler's version. A Settings switch turns the launch check off.
Setup testWhen you click the test on the setup screen, one request to https://example.com.
Other devicesTrawler listens only on this machine until you allow another device; then it also listens on the one network address you chose.

Everything else Trawler sends is the traffic you route through it, going where it was already going.

The settings switch is the plan's Q5 ruling, built in W4; the line ships only with it. Linux path follows Tauri's app_data_dir ($XDG_DATA_HOME when set) — W12 confirms each path on a real install.

Sample entry

## 0.1.0 — 2026-MM-DD

The first public release.

### New
- Capture HTTP and HTTPS from this machine, an iPhone or Android phone,
  the iOS Simulator and the Android emulator, set up from one screen.
- Filter the list with chips such as `status:4xx` or `-method:OPTIONS`.
- Read headers, timing and bodies, with viewers for JSON, XML, HTML,
  forms and more; open any value in its own window.
- Send a request again, edited, or write one from scratch.
- Export what you captured to HAR, and open a HAR file.
- Keep capturing with the window closed, from the menu-bar or tray icon.
- Update from inside the app. Every update is signed.

### Known limits
- HTTP/3 traffic isn't captured.
- On Windows and Linux, remove Trawler's certificate by hand (see the guide).

### Check your download
macOS / Linux:  shasum -a 256 -c SHA256SUMS --ignore-missing
Windows:        Get-FileHash .\<file> -Algorithm SHA256  (compare with SHA256SUMS)
