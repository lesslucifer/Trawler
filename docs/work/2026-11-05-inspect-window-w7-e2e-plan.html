Journeys

JourneyAssertsEpic rows
J1 · open and focusthe /bigjson response shows a cut in the pane; open in data window on the CutMarker → a second handle data-…, its title the opener's caption, the document's last line present; open in data window from the pane's toolbar → still two handles1, 2
J2 · work a JSON documentfind reports the seeded count and steps to the next match; ⋯ → sort keys, then a typed edit → modified; copy yields the edited text and ⋯ → copy original the served bytes (a recording clipboard, as flows.spec does); undo twice → no modified; an edit, then ⋯ → restore original → no modified and copy yields the served bytes4, 5, 9
J3 · a long form and a tokenthe /bigform response opened → the last pair present and whole; find on one key counts 1; right-click the token value → decode → decoded as JWT with header and payload; ↗ → a third handle holding the payload JSON; right-click 1793851200 there → decoded as time, its UTC line 2026-11-05 04:00:00Z (zone-independent)6, 8
J4 · no write-backafter J2's edits the main window's pane still shows the captured body; GET /flows/{id}/response/body returns the served bytes; no data window's resource timeline holds an http(s) entry; each data window closed → the main window stays, nothing is asked10, 2
