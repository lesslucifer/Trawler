Requirement

Every string the app splices into a privileged script is escaped for each layer it crosses: the AppleScript literal of do shell script (\ and "), the shell inside it (single quotes), and on Windows the PowerShell single-quoted literal (') and the command line Start-Process joins (an argument with a space).
