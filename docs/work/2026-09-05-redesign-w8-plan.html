E-REDESIGN.W8 — build the body viewer

The epic's first build against a full screen design. Nine registry members replace six inline renderers and a ModeButton; XmlRenderer gets its first reachable surface, bodies state their truncation, and the leg leaves the pane for the panel that already splits it.

WU plan · 2026-09-05 · Trawler · T3 (docs/work/) · wu/redesign/body-viewer-build → epic/redesign · designed by design run #9 · W7 plan · W7 result

Requirement

Build — citing design run #9 by blob, not re-deciding it — a BodyViewer that takes leg as a prop and renders one body: the six kinds dispatched to JsonRenderer · XmlRenderer · TextRenderer · HexRenderer · FormRenderer · ImageRenderer, the mode switch to SegmentedControl, the two actions to CopyButton + IconButton, and all seven zone states to Notice; with FlowDetail mounting one pane per leg under its own heading — so that a body over the cap states its truncation through CutMarker instead of silently swallowing it, an XML body renders as XML instead of falling through to text, a JSON body copies as valid JSON, the copy label reverts, and BodyViewer.tsx:112's marker is closed.

What could go wrong

RiskHandling
The build re-decides what a member owns. The natural failure of consuming nine dense contracts is to re-implement a cap or a marker at the call site. The screen sets no threshold and mounts no CutMarker. Every cap is the member's; the screen's only truncation duty is pinning zone C to B's foot. A call site that passes a max is a review finding.
The existing tests encode the old design. BodyViewer.test.tsx asserts a <details> tree, leg tabs and a sticky copied — all three are things this WU deliberately removes. Rewritten, not patched, and the rewrite is itself the evidence: each deleted assertion maps to a design line that removed it. A test kept green by keeping the defect is the failure mode.
SourceSurface is CodeMirror. JsonRenderer and XmlRenderer mount a real editor; jsdom may not render its text the way a naive assertion expects. Assert the member's data-testid and the copy payload, not CodeMirror's internal DOM. The nine members already have passing tests at this tip — those are the reference for what is assertable.
The e2e leg selectors move. flows.spec.ts asserts on testids, and the two-pane change adds a second instance of every body testid to the page. Scope each e2e assertion to its leg's section rather than to a bare testid, and fix the spec in this WU rather than leaving W11 a broken suite.
The toolchain is not on PATH. This worktree's ~/.cargo/bin is empty. ~/.rustup/toolchains/stable-aarch64-apple-darwin/bin prepended; verified working, and ui/node_modules is installed. An environment note, not a finding.
