E-PRORELEASE.W2 — third-party notice shipped in the app

~560 release crates and ~60 npm packages ship inside every installer; their licences (MIT, Apache-2.0, BSD, MPL-2.0, CDLA, Unicode, OFL fonts) require their text to travel with the app, and nothing generates or bundles it.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W2 · branch wu/prorelease/third-party-notice off epic/prorelease · epic plan E-PRORELEASE

Requirement

cargo xtask licenses writes the committed THIRD-PARTY-NOTICES.txt: Trawler's own MIT LICENSE first, then every licence text of the crates the app's release build links (normal dependencies of trawler-ui, every platform) and of the UI's production npm packages, each text once with the packages it covers; a package without a licence file gets the standard text of a licence its expression offers. The app bundles the file as a Tauri resource, never as bundle.licenseFile (DEC-87).
