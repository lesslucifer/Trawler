E-INSPWIN.W8 — time decoder

Decode a timestamp or a date-time string the same way W6 decodes a token: the peek under it shows the instant in the user's local time, beside UTC and how long ago or ahead it is.

v1 · 2026-11-05 · Trawler · T3 WU plan · E-INSPWIN.W8 · branch wu/inspect-window/time-decoder · epic plan · extends W6

Requirement

In the data window, decode (right-click or ⌘⇧D) on a Unix timestamp or a date-time string with a zone reads it as time: the peek shows the instant in the user's local time and zone, in UTC, and how long ago or ahead it is, and says what it was read as; a date-time that names no zone or a date off the calendar says why; ⇄ replaces the value with the local time as one undoable step and ↗ opens it as text.

Mapping

E-INSPWIN · UC-9 decoder rows · epic expected row 8 (time) · Q13 · extends W6's decoders.ts, the DecodePeek and decodeAround; no new component, no new menu row or key.

Choices this plan makes

ChoiceTakenWhy
a date-time that names no zonerefused: it names no zone, so it cannot be moved to local timeguessing UTC or local would show a wrong instant without saying so; flag for the owner's try-out
a run of digits that is a timestamp and valid base64time wins, no switchbase64 of ten digits is binary with no signature, which never reads well (W6's rule); W6 dropped the switch
timestamps before 1973 or past 2286 in secondsnot read as time (their digit counts are not a unit's)the digit count is the only unit signal; a short number is far likelier an id than a date
local time format2025-11-05 11:00:00.25 +07:00sortable, the offset explicit, the zone name beside it in the label
