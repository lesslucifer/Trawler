E-INSPWIN2.W8 — build: the find bar takes the query bar's UX

The data window's find becomes a chip box over a find grammar: text and keyed chips, suggestions for the kind's keys, faults and refused chips; every chip and the draft mark, and find still never narrows.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · branch wu/inspect-window-v2/find-chip-bar off epic/inspect-window-v2 at 4a71c17e · epic plan: E-INSPWIN2 · design: ChipBox, docs/work/components/chip-box.html (owner-confirmed; archived: retired into ChipBox.tsx's TSDoc by this WU) and W3's run (E7, E8) · record: DEC-76

Requirement

In a data window, find is typed the way the flow list's filter is: Space or Tab makes a chip from the draft, suggestions offer the keys the kind offers (and the document's keys after key:), Backspace in an empty draft removes the last chip, and a draft that does not parse says why and makes no chip. Every chip and the live draft mark their matches as one set with one count and one step order; a chip the current kind cannot run is refused and marks nothing. The flow list's query bar behaves exactly as before.
