E-BGSVC.W4 — Trawler at login

One login entry per OS, written by Trawler itself, starting this binary with --background, and read back from the OS every time.

v1 · 2026-11-05 · Trawler · T3 (docs/work/) · WU plan · branch wu/bg-service/login-item off epic/bg-service · epic plan: E-BGSVC

Requirement

Writing the login item on creates (or replaces, whichever binary it named) the OS's own login entry starting this binary with --background; writing it off removes it. Reading it reports on whenever such an entry exists, with the program the entry starts. Every entry lives under a root the caller passes, so a test never touches the real login items.
