E-INSPWIN.W3 — the data window, built

The screen W2 designed, mounted in every data-* window: the payload rendered whole, a working copy with one history, the ⋯ and right-click menus, and the pane's way in. Every data window shares one remembered size and place.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-INSPWIN.W3 · branch wu/inspect-window/data-window-build · epic plan · builds the design run

Requirement

A data-* window claims its payload and renders it whole as the kind detected from typeHint or the bytes (overridable), on an editable working copy whose every change is one undoable step and whose restore original returns the exact original bytes; copy and save deliver what is on screen and the ⋯ menu the original; BodyViewer and its CutMarker open it; and every data window opens at, and writes, one shared geometry record.

Mapping

E-INSPWIN · UC-9 open, whole data, working copy · UC-5 entry point · epic expected rows 1, 3 (render and fold), 5 (free edit, undo, restore), 7 (render), 9 · Q11 as re-ruled on 2026-11-04 · builds the run's proposals Menu, EditSurface, FormTable, HexView, the CutMarker delta, DataWindow, StatusBar and the glyphs more, window, add.
