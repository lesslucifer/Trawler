Mockup

Mounted from the real ui/src/components/. The page sidebar is drawn by the screen: it is a proposal. The dialog's frame is ModalShell, build-local, as DEC-64's dialog uses it. Each button shows one state — read each alone.

overflow: pages — two names in a column, pinned while the page beside it scrolls · page title — one line · keep capturing — one row, one line and at most one notice, bounded · at login — one row and one line, bounded; its entry path shows only in the native tooltip, which wraps it · capture service page — unchanged, its log keeps its own scroll (owner: that page) · once-question — one title, one sentence, two answers at dialog-max wide, bounded. Where the window is shorter than the page, the page scrolls.

Payload: only the login entry's program path, such as /Applications/Trawler.app/Contents/MacOS/trawler-ui, read verbatim. Nothing else on the page is wire data.
