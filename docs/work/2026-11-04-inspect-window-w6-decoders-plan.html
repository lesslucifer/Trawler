E-INSPWIN.W6 — decoders

Decode a selection or a form value in place: a peek under it reads base64, URL-encoding or a JWT, offers only the decoders that read it, replaces it as a working-copy step, or opens the decoded bytes in a data window of their own.

v1 · 2026-11-04 · Trawler · T3 WU plan · E-INSPWIN.W6 · branch wu/inspect-window/decoders · epic plan · builds the design run

Requirement

In the data window, decode (right-click or ⌘⇧D) on a text selection or a form row's value opens a peek under it that reads the value as base64 (standard or URL-safe, padding optional), URL-encoding or a JWT (header and payload as JSON, the signature shown and never verified), offers only the decoders that read it, a switch only when more than one does, and says in words why when none does; ⇄ replaces the value with its decoded form as one undoable step, and ↗ opens the decoded bytes in a new data window — a binary result only that way, as hex or image.

Mapping

E-INSPWIN · UC-9 decoder rows · epic expected row 8 · builds the run's local DecodePeek (D4: under the line, pushing lines down, scrolling past 256 px), the right-click decode / decode the value rows (D6), ⌘⇧D, and IconButton's replace ⇄ glyph. W3 built the EditSurface and FormTable insets it mounts in.
