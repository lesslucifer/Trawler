The model — assign each element a reusability tier

Elements decides, per element, which tier of the epic's reusability ladder it is (fixed in design-flow-discussion.html). Higher tiers may use lower, never the reverse:

TierExampleIn collection?Contract
T0 · FoundationHTML / native / libno — external, fixeduse only when nothing higher fits
T1 · Primitivebutton, input, labelyesreuse-first · no business logic
T2 · Widgetstatus button, searchbaryesreuse-first · has business logic
T3 · Locala screen rownobuild local, waive reuse
T4 · Compositiona panel, a screennobuild local, waive · break into lower tiers

The T1↔T2 line is exactly business logic: a primitive is presentation only; a widget carries logic (status→tone mapping, search behavior, decode). The collection = T1 + T2; T3/T4 are local code with a waiver; T0 is external.

The collection is empty in W1, so nothing can actually be reused yet. Every T1/T2 below is therefore a propose-new seed — it passes with a spec now, gets built + human-approved later (the reuse-or-propose rule). Every T4 is local+waived but complex enough to break down into lower tiers — that breakdown is W4. (Tier calls below are mine, for you to review.)

T4 compositions — break down in W4

The two components too big to be collection entries. They are built local to this screen (waived from reuse), but each decomposes into lower-tier parts — and those parts, if reusable, become the real T1/T2 collection seeds. The decomposition is W4 work:

  1. header table (T4) → key/value row (T1) · select/copy a cell (T1 behavior) · copy-all-as-headers — reserialising to wire-format header text is business logic → T2. Users need both select-and-copy and copy-whole-table; worth its own consideration.
  2. body viewer (T4) → the per-type renderer family (JSON tree · XML · image · form · hex — each likely a T2/T3 of its own) · raw/decoded toggle (decode = T2) · copy button (T1, reused) · save. The most complex node in the screen.

Everything else is a T1 primitive except status pill (T2). With the collection empty, all of those are propose-new seeds pending W2.
