E-PRORELEASE.W16 — remove the certificate on Windows

The macOS remove the certificate button, on Windows: the machine Trusted Root copy that set up this PC wrote leaves under the one UAC approval set-up uses; the by-hand steps lead with that store.

v1 · 2026-11-06 · Trawler · T3 WU plan · E-PRORELEASE.W16 · branch wu/prorelease/windows-remove-cert off epic/prorelease · epic plan E-PRORELEASE · owner ruling Q1

Requirement

On Windows, once the certificate task reads trusted, task 1 offers remove the certificate exactly as macOS does; it deletes the live certificate (by SHA-1 thumbprint) from the machine ROOT store through the same UAC Start-Process -Verb RunAs set-up uses, or from the user's ROOT store unelevated when only that holds it; a cancelled approval reads as the approval was cancelled; the by-hand steps name the machine store first.

Flow

flowchart LR
  B[remove the certificate] --> R{certutil -store ROOT · -user -store ROOT}
  R -- a store did not answer --> E[couldn't read the certificate stores]
  R -- machine holds it --> M["UAC: certutil -delstore ROOT ‹thumbprint›"]
  R -- only the user's holds it --> U["certutil -user -delstore ROOT ‹thumbprint›"]
  R -- neither --> N[nothing to run]
  M & U & N --> T[trust re-read → task 1 not done]
