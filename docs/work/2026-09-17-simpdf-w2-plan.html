Requirement

A design run written to DEC-53's shape — one mockup doc carrying mockup · capabilities · keyboard · proposals · blocked-on · review — is green at Tier-1, a run still carrying a cut item is red with a named check, and no predicate passes vacuously: every Frame, Layout, Elements, Interaction, Tune and receipt predicate is removed rather than left unreachable, overflow-declared and wire-order-preserved read the mockup's own plain HTML, keyboard-parity reads the Keyboard item, and state-declarations leaves the rulebook with its predicate. The rulebook pin exists nowhere — not in a receipt, not on the design/v1 note, not in the gate, not in what design-scope prints. The design step is design-scope, the hand-off accounting and the note, with the verdict following the accounting alone; the design finder and its rubric are gone. docs/design-flow.html, the rulebook, the checker's failure output and the skill all state that one shape.

One check loses its input, and the plan should say so before the diff does. mockup·hand-drawn asked "every catalog row verdicted reuse or extend is mounted, never drawn" — its owed list came from the Elements catalog, which this WU cuts.
