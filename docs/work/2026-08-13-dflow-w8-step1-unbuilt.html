Deviation from the plan. The plan (and Q1 before it) recorded "three were never built; BodyViewer's code exists outside the registry". Reading the tree instead of the plan: one was never built, and the other three were all built — under a different name, in a different folder, or without ever being extracted. The drop record is the one place these facts are written down, so they are written down as they are.
