DEC-26 — a mockup mounts the components it claims to reuse, and a skip that prints nothing is a pass

W5 made a specimen the component itself. The design run never migrated, so run #4 hand-drew seven components the registry already ships — in faultless utilities, past a green gate — and the one check that could have said so was structurally unable to fail.

DEC-26 · 2026-08-14 · Trawler · E-DFLOW.W9 ④.5 · status: active

Context

Two migrations, one finished and one that stopped where nobody was looking.

What W5 builtWhere it reached
scripts/build-specimens.mjs compiles ui/src/components/, React and the app theme into one classic script a file:// page can run, read as window.Trawler. The specimen IS the component, with "when" changed from load time to author time component design files: 5 of 20 loaded it at the W5 merge and still did at W7 — every one has since been retired under DEC-16. Design runs: 0 of 4, ever
scripts/check-render.mjs, the render gate: real Chrome, real file://, a clean console and every mount non-empty reachable only from cargo xtask ui specimens --check. The installed hooks call verify-dod, which never invokes it. Live population at W9: 1 doc — the W5 record that announced the migration

The two facts compound. A run doc drew its components by hand; the gate that checks rendering returned early on any file that did not already load the bundle, and the loop continued past that skip without printing it:

if (!source.includes('specimens.bundle.js')) return { file, skipped: 'not migrated' };
node scripts/check-render.mjs <run #4> → "all migrated design files render", exit 0, on a mockup that hand-drew all seven of the components it declared reuse or extend. This is DEC-15's silence-reads-as-pass, inside a script: the check could not fail on the artifact it existed for.

Tier-1 pointed the other way at the same time: assets·specimen required the pre-bundle trio — the CDN, tw-config.js, specimen.js — so the predicate encoded the unmigrated shape as the mandatory one.

Why no other check could catch it. The vocabulary predicates judge class membership. Run #4's imitation used the components' own utility strings, copied correctly, so every class resolved and every rule went green. A hand-drawn reuse is the one fork that is invisible to a check about classes, because the classes are right — what is wrong is that the rendering is the doc's own invention, and nothing binds it to the component the catalog named.

Choice

A design run's mockup mounts every component it verdicted reuse or extend. Only a propose row, a build local element and an extend's declared delta may be hand-drawn — each declared, one comment each. Imitating a built component is refused, not reviewed.

How a mount is seen

By the component's element name, not by a marking. A marking is exactly what a hand-drawn imitation can also carry — run #4's drawing carried every data-key the element map demanded. <section> is the browser's tag; <Section> is the collection's, and only one of them can be drawn.

One tag, and not its parts twice

assets·specimen now accepts either shape, and refuses the overlap:

ShapeVerdict

a mount with no bundlered — an empty div beside correct prose reads as "no specimen here" rather than "broken"

A skip is printed, and for a live design artifact it is a refusal

check-render.mjs keeps its shape and loses its silence: every skip prints, a skip on a doc that is not a design artifact is counted rather than listed, and a live design artifact that loads no bundle fails. An archived run is skipped by name — closed under an older contract, the same reason Tier-1 exempts it. The gate also learned the run's mount convention: a design file mounts per specimen (spec-*), a run mounts per zone inside data-item="mockup".

Not wired into verify-dod. It drives a real Chrome and the DoD gate is hermetic — headless cargo build and cargo test stay GUI-free. Fixing the skip is what made it able to fail; putting a browser in the merge gate is a separate call.

Cost — measured, not assumed

check_vocabulary scans authored classes, and the tokeniser treats a <script> body as data. So every class a mounted component draws, and every class the run writes inside its mount script, leaves Tier-1's sight. Taken over run #4's mockup, before and after:

The honest summary. The migration is not a straight trade of one blindness for another — 50 of 53 departing tokens are gated at their source, and two predicates lose a population they should never have had. What genuinely goes unchecked is small and named: three tokens, and four of five payload markings. The fix is one change — teach the tokeniser to read className and attributes inside a text/babel block — and it is deliberately not in this Working Unit, because widening the scanner is its own change with its own red-before-green.

Alternatives

ConsideredRejected because
keep composing by class name, and add a rule that the strings match the component's it is a diff between two copies, and it goes green the moment someone updates both. The gap this closes is not "the strings drifted", it is "the rendering is the doc's own"
see the mount through data-key on the host, as the W9 plan proposed run #4's hand-drawn imitation already carried every key. A marking a drawing can carry proves nothing; the element name cannot be drawn
make check-render.mjs the enforcement, since it renders it is in no gate, and putting a browser in a hermetic merge gate is a bigger decision than this one. Tier-1 refuses statically; the render gate proves the mount is not empty
widen the class scanner to read JSX in the same change it is a second red-before-green on a different subject. Named here with its measurement so it is a follow-up rather than a discovery

Consequences

  • Run #4's bytes changed, so its DEC-25 citation re-pins and the amendment re-enters Tier-3 on the merge that lands it. That is the blob pin working.
  • A run that mounts needs Babel in the head — the mockup is JSX now, compiled in the browser like a component design file's specimens.
  • An extend mounts its base; the delta is the only part it draws, and it is drawn where a reader and the gate can both see it (the run's own stylesheet), not smuggled into a copy of the component.
  • The stubbed layer nearly empties. Run #4 stubbed Select's popup, CopyText's clipboard and StatusLine's spinner; mounted, all three are real.
