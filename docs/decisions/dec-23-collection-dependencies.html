DEC-23 — the two dependencies the component collection added, and how each one leaves

Both were taken because the browser has no equivalent and the hand-built version is a table that drifts. Each carries its exit path, written before anyone needs it.

DEC-23 · 2026-08-12 · Trawler · E-DFLOW.W7 · distilled from StatusPill D5 · TimestampText F5 · status: active

Context

The house rule is never to add a dependency for what a few lines can do. Two component forks argued past it, and both arguments turn on the same thing: the "few lines" is a table of external facts, and a copied table is a table that goes stale silently. A later reader asking "why is this here?" gets the answer once, here.

Choice

DependencyForWhy not by handExit path
statuses (jshttp)
~2 kB		 StatusPill's reason phrases — statuses.message[404] → "Not Found" The alternative is ~60 lines of copied IANA table that drifts as codes are added, with nothing checking it. No stdlib alternative exists in the browser: http.STATUS_CODES is Node-only and unavailable in the Tauri webview bundle. The package is zero-dependency, IANA-sourced, and is the map Express itself uses — so it is maintained upstream and there is nothing to keep in sync here None needed; the upstream is stable and the surface is one lookup
moment TimestampText's three modes — lenient parsing (ISO 8601 · epoch ms · Date), format-token rendering for the default and custom strings, and fromNow() for relative Native Date + Intl is zero-dependency but three hand-built pieces: Date.parse accepts fewer input shapes, custom formatting means inventing a token syntax for the format prop, and relative mode needs hand-rolled unit selection around Intl.RelativeTimeFormat Named at the fork: moment is in upstream maintenance mode. If that ever matters, dayjs shares the same format-token API and the swap is confined to this one component — which is why the format-token syntax was worth paying for rather than inventing

Options rejected

OptionWhy not
A hardcoded status→phrase map Copied IANA data with no upstream. It reads as "a few lines" precisely because the drift is invisible until a reader hits a code the table predates
Native Date + Intl Zero-dependency, and genuinely the lazier-looking answer. Rejected because it trades one dependency for three hand-built subsystems, one of which is a bespoke format-token parser — the thing the dependency exists to not write
dayjs from the start Not rejected on merit — moment was manager direction, and the API compatibility means choosing it now costs nothing later. The swap is a one-component change, recorded above so it stays one

Consequences

  • These two are the whole dependency surface the component collection added. A third component reaching for a library is a new argument, not a precedent set by these.
  • The moment exit path is a constraint on the component, not an intention: anything that leaks moment's API past TimestampText's boundary makes the swap stop being confined, and is a finding.
  • Both land in ui/package.json; the house rule that argued against them is CLAUDE.md's, and this record is the exception it allows for.
