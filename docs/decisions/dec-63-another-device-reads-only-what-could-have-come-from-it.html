Decision. Another device's tasks read traffic that started after the address it uses was allowed. Its own request — an address carrying a mark only its try task shows — settles both of its tasks, named and timed. Other traffic counts only where it arrived between two readings of this machine's proxy as off or another proxy; until something is that device's, each task names what will settle it. Every proof carries its time and lasts the session, whatever this machine's proxy reads after it. An allowed address this machine no longer holds reads not working, and reach is read again with this machine.
