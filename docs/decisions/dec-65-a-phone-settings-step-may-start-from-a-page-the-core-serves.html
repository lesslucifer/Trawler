DEC-65 — a phone's Settings step may start from a page the core serves

The Android device's Wi-Fi proxy step starts from a page on the reach listener. The page names the proxy's hostname and port, and its one button opens Android's Wi-Fi settings. The Settings path stays as the other way.

Decision. The core serves GET /android-wifi, a page for a phone's browser. It names the armed proxy's hostname and port, and its one button, Open Wi-Fi settings, is an intent: link to android.settings.WIFI_SETTINGS. /reach names its URL as wifi_page. The Android device's proxy step leads with that URL's code, and keeps the Settings path as its other way.
