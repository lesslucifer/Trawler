DEC-46 — the design verdict has its own note

E-SIMPWF.W4 takes the design dimension out of the code review's note: the verdict travels as design/v1 on refs/notes/design, written by a design step of its own and read by 9·design — so a diff that carries a design artifact and no code owes the verdict without owing a review.

Decided 2026-09-12 · E-SIMPWF.W4 · active

The decision

The design dimension's verdict is a design/v1 note on refs/notes/design. It carries the section a cr/v3 note carried: the artifacts judged, the rulebook blob it was judged against, its own verdict, the hand-off citations (implements) and the drops (undesigned, dropped). It is written by the design step (.claude/skills/design-review/SKILL.md), which cargo xtask design-scope tells what must be judged, and 9·design reads it and only it.

The note pins design_sha256: the hash of the range's design paths — the artifacts in scope and the rendered files the diff owes an answer for. The rulebook moved under a verdict, or an artifact rewritten after it, is refused rather than silently covered.

A tip that declares cr/v2 or cr/v3 still has its design: section read from its own note, exactly as before, so every already-merged tip — and every seam the epic walk re-verifies — keeps the verdict it shipped. A cr/v4 tip, or one with no review at all, is read from the design note.

The code review spawns no design finder, reads no design artifact, and carries no design: section. Its note has no field for one.

Why it needed deciding

A design artifact is a document. A Working Unit can write a design run and no code at all, and under DEC-45 such a diff asks for no review — the review binds code, and there is none. If the design verdict still lived on the cr note, that diff would owe a review note to carry a verdict about no code: the two rules would contradict each other, and the contradiction would be resolved every time by whichever check ran last.

Keeping the verdict on the review's note also kept it inside the review's blast radius. W4's rule is that no document is judged, cited or bound there; a design verdict is a judgment about documents, so it has to travel somewhere else to be true.
