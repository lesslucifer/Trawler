DEC-90 — About is the app's own, and the shell names its links

One About window on every OS; the webview asks for a link by name and the shell builds the address; the launch update check obeys a stored switch.

The rules

#RuleWhy
1About is Trawler's own window (label about) on every OS; the system About panel and the default menu's About items are replacedowner ruling D1: one surface with the logo, licences, privacy and working links everywhere
2The webview opens a link only through open_link, which takes a closed name (guide · issue · source); the addresses are shell constants and no opener permission is granted to any windowno page, however it got there, can make the shell open an arbitrary address
3A report carries the version, the OS with its version and CPU, and the install kind — never the capture, a host or the machine's nameowner ruling D5: what a triage asks first, nothing private
4The launch check runs only when the copy is installed, check for updates automatically is on and the check is due; a missing or unreadable answer reads on; Check for Updates… and check now always runplan Q5: a switch, default on; the user's own check is never silenced
5The About window's capability is core:default and closing itself; it reads the notice the bundle ships (DEC-88) and nothing else from diska read-only window needs no file or dialog reach
