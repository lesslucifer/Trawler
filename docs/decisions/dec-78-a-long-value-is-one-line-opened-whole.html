DEC-78 — a long value is one line, opened whole

A value whose whole is one named act away in a data window may be cut to one line with an ellipsis. This is the second escape from wrap-not-truncate.

Why this record exists

TodayThe limit
A header value over three lines is clamped with more / less; the URI wraps whole a few cookies or tokens bury the panel, and every value is read by expanding it in place
wrap-not-truncate: no ellipsis on a payload element, the one escape a fixed-height row (DEC-34) the data window (DEC-76) now shows any value whole, but the rule gives that route no standing

Decision. A wire value whose whole is reachable by one named act that opens it in a data window — its own open, or its section's open all — renders on one line, cut at the end with an ellipsis when it is wider than its column. The more / less clamp is retired with it.

The rules

#RuleWhy
1The route is named on screen: an open on the value, or an open all on the section that holds it, which hands every value of the section wholea cut is honest only when the way to the rest is in sight
2The cut is visible: an end ellipsis, never a silent clipthe reader must know there is more
3Clicking a cut value still copies the whole value (CopyText)copy delivers the evidence, not what fits
4The column never widens and the panel never scrolls sideways for a long valuethe escape exists to keep the panel's shape
5Only values with such a route gain the escape; everything else wraps, and list rows keep DEC-34the escape is earned per value, never a style
