One licence file; every other source states the same licence and holder. package::metadata_drift names any source that disagrees.

The rules

#RuleWhy
1Trawler is MIT. The root LICENSE is the MIT text with Copyright (c) 2026 Vu Luu; every workspace crate, ui/package.json and bundle.license say MIT; bundle.licenseFile stays unset (Q1)the crates already declared MIT; GitHub and every package manager read the same terms. A licenseFile makes tauri-bundler embed it as the .dmg's licence agreement: Finder asks the user to agree before it mounts, and hdiutil attach stops at the prompt (seen in package_bundle, E-PRORELEASE.W1). MIT asks no acceptance
2Vu Luu is the copyright holder, the bundle publisher and every crate's authors; the bundle copyright is Copyright © 2026 Vu Luu (Q2)without publisher Tauri derives one from the identifier (trawler), which Windows shows in Apps and the installer
3Every crate is publish = false; the name stays Trawler (Q10)the crates.io name trawler belongs to another project; a cargo publish must never be one command away
4homepage is the GitHub repository in every crate and the bundle; the bundle carries a longDescription and linux.deb.section develdeb, rpm and the Windows uninstall entry show them; empty fields read as an unfinished package

Known limits

LimitWhy accepted
The year in LICENSE and the bundle copyright is fixed at 2026the first publication year is the one that matters for MIT; a later range is a one-line edit the check names
No installer shows the licence text; it ships in the repository and (W2) in the app's noticesMIT asks only that the notice travels with the software, which W2's bundled notice carries
Third-party licences are not covered herethe shipped notice of every dependency's licence is E-PRORELEASE.W2

Held by

package's unit tests (metadata_drift_of per field, and the tree has none) pin rules 1 to 4; xtask/tests/package_bundle.rs proves the packaged macOS app's Info.plist carries the copyright. The Windows and Linux installers' metadata is a hand check on the next rc.
