DEC-12 The primary UI is a native desktop app, an out-of-process client of the control API

Statusaccepted · 2026-07-12 · Owner · partly superseded by DEC-68 (2026-11-03): the out-of-process topology and the GUI-free root build. The stack, API-first, design system, CORS grant, API base URL and web shell clauses stand
SupersedesThe roadmap's web-primary / single-binary framing — a strategic reversal (see below).

Decision

  • Stack: Tauri 2 + Vite + TypeScript + React + Tailwind, mirroring the sibling Strata app rather than re-deriving it. Add @tanstack/react-virtual for the long streaming flow list. The front end lives in ui/ alongside the core.
  • Topology — out of process: the app is a pure client of the existing control API (127.0.0.1:7421, REST + SSE). The Tauri Rust side (ui/src-tauri) is a thin window shell — no core logic, no capture, no new API. This preserves the API-first invariant: everything the app shows is equally reachable with curl. The core workspace excludes ui/src-tauri so a headless cargo build/test stays GUI-free.
  • Design system — Warp: seeded from Warp's DESIGN.md. Warm-dark canvas #2b2622, off-white ink #f7f5f0, hairline borders, Inter / DM Mono / Instrument Serif, 4px spacing, tight 3–4px radii — as the Tailwind theme plus a base component kit. Warp is "zero chromatic accent"; the one deliberate exception is functional status color (2xx→ok green, 4xx·5xx→warn red), because a debugging proxy must tell success from error at a glance.
  • CORS grant on the control API (consequence, Owner-approved): the native webview is a cross-origin client, so its fetch/EventSource are blocked unless every API response carries Access-Control-Allow-Origin: * (and OPTIONS preflights short-circuit). The grant is safe because the API is a read-only loopback inspection surface bound to 127.0.0.1 — * adds no exposure the bind address does not already imply. This is the one API-response change the epic makes; the plan had listed API changes as a non-goal, so it is recorded here explicitly.
  • API base URL is configurable, never a hardcoded port in component code: a runtime value (window.__TRAWLER_API__ / sessionStorage) wins over the build-time VITE_TRAWLER_API, which wins over the :7421 dev default. The released app exposes it as configuration; tests inject an ephemeral port.
  • The web shell is kept alongside as a second client of the same API, to be retired later at native-UI parity — not this epic.

The reversal

The roadmap framed the UI as browser-primary (the E-UISHELL web shell) inside a single binary. DEC-12 makes the native app the primary, designed surface and the foundation later UI epics (E-UIINSPECT inspector, E-UISETUP onboarding) build on. The core stays a single binary; the app is a separate out-of-process client, so the API-first architecture is strengthened, not diluted. The living roadmap records the reversal.
