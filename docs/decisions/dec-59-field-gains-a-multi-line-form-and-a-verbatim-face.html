DEC-59 — Field gains a multi-line form and a verbatim face, and the edited mark stays the screen's

The composer needs a body box and wire-shaped text. Both become options of the one text input, not a second one. Whether a value was edited is a comparison, and the screen draws it in words.

Why this record exists

DEC-30 built Field single-line, for the filter bar. The replay composer's design run proposed two deltas to it, and the owner's round held them. Decisions are append-only, so the fork is recorded here and the contract moves into Field's TSDoc.

Decision. Field takes three options under one contract. multiline renders a textarea in the same box. verbatim sets the mono family. readOnly keeps the box focusable while the act it feeds runs. It still judges nothing: no invalid state, no edited state, no colour.

What it rules

RulingWhy this wayRejected
multiline is an option of Field. It uses the same border, radius, padding and states. The caller sets its height with a class, the same way the caller sets its width. It never resizes by hand two boxes that must be kept identical drift apart, and that drift is what DEC-18 and DEC-30 were written to end. The import dialog's hand-made textarea was the first sign of it, and it now uses Field a separate TextArea entry · a textarea that grows with its content, which moves everything under it on each line typed
verbatim sets the mono family mono-for-wire-data covers every value sent as typed (a URL, a header, a body). Field used the ui family because the filter bar types chrome. Passing font-mono through className only worked because of stylesheet order overriding the family through className · a mono default, which would make the filter bar's chrome look like wire
readOnly is a state, dimmed like disabled a disabled box drops focus to <body>, outside a modal, where Esc is never heard. The import dialog relies on this hold, so moving it onto Field brings the state with it leaving the import dialog on its own textarea, which keeps the second box
The edited mark is the screen's, in words: edited + revert, added and follows the URL, in a slot after the value edited means compared with the seed. Field holds only the value, so it has nothing to compare. DEC-19 leaves no colour for edited, so a word carries the mark and colour-plus-text is met without a colour an edited state on Field · a tinted border · a zone-level modified badge, removed during run #7's Tune step because the row says more
A malformed value gets no red border the core judges a URL when it is sent and answers 400 url must be absolute http(s). The send zone shows that answer in words. Checking in the box would add a second judge that can disagree with the first an invalid state on Field (DEC-19 has no token for one)
