DEC-83 — CI is a signal on main, not a gate

GitHub Actions builds and tests what landed, on platforms this Mac cannot be. It never decides what lands.

v1 · 2026-11-05 · Trawler · T2 decision · minted by E-CI.W1 from the owner's rulings Q17 and Q19 on E-PKG2's plan · no use case (infrastructure) · relates to DEC-74 · active

The rules

#RuleWhy
1.github/workflows/ci.yml runs on a push to main and on workflow_dispatch, and on nothing else: no epic/*, wu/* or pull-request trigger (Q17)main is what shipped. A branch runs only when someone asks
2A branch is run by hand: gh workflow run ci.yml --ref <branch>. GitHub can dispatch only a workflow that exists on the default branch, which is why this file reached main before the platform work that needs it (Q19)Windows and Linux fixes are seen before the epic merges, without CI on every push
3CI runs clippy with -D warnings and the trawler and trawler-ui tests, after installing the UI's packages from the lockfile. xtask's gate suites, vitest, the WebDriver e2e and nextest stay localthe core and the app are what each platform must build and run. The gate tooling is macOS-only and local by DEC-74
4Nothing refuses on a CI result: no required checks, no branch protection, no hook that reads it. The local gates are the gates (DEC-74). A red run is a finding for the next epic that touches that platforman unattended, AI-first merge cannot wait on a remote service. Owner ruling Q17: a signal, not a gate
5The workflow reads the repository and writes nothing (contents: read). A newer run on the same ref cancels the older one. A run stops after 45 minutes. No step may continue on error or be skippedleast privilege; one answer per ref, the newest; a hang on a runner billed at ten times Linux's rate is cut off; a signal that cannot go red is no signal

Held by

xtask/tests/suite/ci_workflow.rs pins rules 1, 3 and 5: the triggers, the job, its setup and commands in order, the permissions, the timeout, and that no step can fail quietly. Rules 2 and 4 are facts of GitHub and of the hooks: no hook reads a CI result.
