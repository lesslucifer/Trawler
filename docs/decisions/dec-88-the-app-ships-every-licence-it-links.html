DEC-88 — the app ships every licence it links

One generated notice carries Trawler's licence and the licence text of every crate and npm package inside an installer.

v1 · 2026-11-06 · Trawler · T2 decision · minted by E-PRORELEASE.W2 · UC-INSTALL · relates to DEC-87 · active

The notice

flowchart LR
  M["cargo metadata: normal deps of trawler-ui, every platform"] --> G["cargo xtask licenses"]
  P["pnpm licenses list --prod"] --> G
  L["LICENSE (MIT, Vu Luu)"] --> G
  S["xtask/licenses/: MIT · Apache-2.0 · BSD-3-Clause · MPL-2.0"] --> G
  G --> N["THIRD-PARTY-NOTICES.txt (committed)"]
  N --> R["bundle.resources → every installer"]
Generated, committed, bundled. A unit test regenerates it and fails when it is stale.

The rules

#RuleWhy
1The scope is what an installer carries: the normal-dependency closure of trawler-ui on every target platform, plus the UI's production npm packages (fonts included); build-dependencies and dev-dependencies are outa licence binds the copies distributed; one file serves every OS's installer, so it lists every platform's crates
2Trawler's own LICENSE comes first, then each distinct licence text once (whitespace-insensitive) followed by every package it coversMIT asks its notice to travel with every copy, Trawler's included; ~600 packages share ~300 texts
3Texts come from each package's own LICENSE* / LICENCE* / COPYING* / NOTICE* files (never *.spdx tags) and the manifest's license-file; a package with none is listed under the standard text of a licence its expression offers (MIT, then Apache-2.0, BSD-3-Clause, MPL-2.0) with its authors as holders; an AND expression or no offered standard text refuses by name~45 crates (objc2, webview2-com, selectors…) publish no file; a refusal beats a silently incomplete notice
4THIRD-PARTY-NOTICES.txt is committed at the root and regenerated with cargo xtask licenses whenever Cargo.lock or pnpm-lock.yaml moves; the drift test names the commanda reviewer sees licence changes in the diff; the release never ships a stale list
5The notice ships as a Tauri resource (bundle.resources: Contents/Resources/ on macOS, beside the binary elsewhere), never as bundle.licenseFilelicenseFile turns into a .dmg agreement prompt (DEC-87 rule 1); W4's About opens this file

Compatibility with MIT

MIT · Apache-2.0 · BSD · ISC · Zlib · BSL-1.0 · Unlicense · 0BSD · BlueOak-1.0.0almost every crate and npm packagekeep the notice (Apache: its NOTICE too) — the file does

Unicode-3.0unicode-ident and the ICU crateskeep the notice
OFL-1.1Inter, DM Mono, Instrument Serifbundled with software is allowed; keep the licence; never sell the fonts alone
LGPL-2.1-or-laterr-efi (offered as MIT OR Apache-2.0 OR LGPL)none: taken under MIT

Known limits

LimitWhy accepted
The drift test runs a full cargo metadata, which fetches other platforms' crate sources oncethe same fetch a build does from the lockfile; no test server or public endpoint is called by the test itself
The file is ~0.9 MB of plain textit is the complete set of texts the licences require; dedup already halves it
A licence change inside an unchanged crate version is not detecteda published crate version is immutable

Held by

licenses' unit tests (render dedups and orders, falls back, refuses; files read, tags skipped; the committed notice is the generated one; MPL, CDLA, Unicode and OFL texts present; the conf bundles it) and xtask/tests/package_bundle.rs (the packaged Trawler.app carries the committed file).
